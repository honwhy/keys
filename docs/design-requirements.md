# KeyTune 设计素材需求 · iPhone 16 Pro / Pro Max Safari 横屏

> **KeyTune · 键音 —— Play by Keys**
>
> KeyTune 是一款专为手机横屏设计的轻量音乐小游戏。玩家根据屏幕提示，在 15 键虚拟钢琴上按下对应琴键，跟随旋律完成演奏；系统用 PERFECT / GREAT / GOOD / MISS 判定每次按键，以 Combo、得分和评级给出即时反馈。你既可以跟着曲目挑战节奏，也可以自由弹奏、识别和弦，还能把整段演奏记录成可回放的作品。

本文是给设计师的最终交付说明。只做 **iPhone 16 Pro / iPhone 16 Pro Max 的 Safari 横屏**，不做通用大而全的素材包。

## 1. 设备、Safari 与安全区

### 1.1 设备参数

| 设备 | 物理分辨率（竖屏） | 横屏物理分辨率 | CSS 视口（竖屏） | CSS 视口（横屏） | DPR | 横屏安全区 |
| --- | --- | --- | --- | --- | --- | --- |
| iPhone 16 Pro | 1206 × 2622 | 2622 × 1206 | 402 × 874 | **874 × 402** | 3 | 左右 62、底部 21、顶部 0 |
| iPhone 16 Pro Max | 1320 × 2868 | 2868 × 1320 | 440 × 956 | **956 × 440** | 3 | 左右 62、底部 21、顶部 0 |

- 屏幕比例约 **19.5:9**，不是 16:9。不要把 1920×1080 设计稿直接裁切使用。
- 主设计画布用 **956×440**，再检查 874×402；两者布局必须一致，只做轻微压缩。
- 横向安全区左右各 62px，是给 Dynamic Island / 圆角 / 前置模组留出的；关键内容不要进入。
- 底部 21px 是 Home Indicator 区域，底部按钮、琴键、进度条都要避开。

### 1.2 Safari 工具栏

Safari 横屏时地址栏/工具栏会占用上下空间，并且会随操作展开/收起。设计不能假设永远有完整的 440px 高度。

| 状态 | Pro Max 可用高度 | Pro 可用高度 | 设计处理 |
| --- | --- | --- | --- |
| Safari 工具栏收起 / 全屏 | 约 440 | 约 402 | 标准布局 |
| Safari 工具栏展开 | 约 **352** | 约 **314** | 紧凑布局：压缩标题区、键盘略矮、隐藏副文案 |
| 竖屏 | — | — | 只显示“请横屏”插画，不进入游戏 |

- 设计稿必须同时给 **标准 956×440** 与 **紧凑 956×352** 两个状态；Pro 用 874×402 / 874×314 检查。
- 不要用固定 `440px` 高度做绝对定位；所有纵向布局要能在 352px 内重新排布。
- 关键操作（开始、继续、暂停、判定区、琴键）必须留在中央安全区，不贴近 Safari 工具栏。
- 页面不允许纵向滚动、横向滚动、橡皮筋回弹。

### 1.3 Safari 适配硬性要求

- 使用 `viewport-fit=cover`；所有安全区用 `env(safe-area-inset-left/right/top/bottom)`，不要写死 62/21。
- 使用 `100dvh`，不要用 `100vh` 做游戏高度。
- 竖屏只显示旋转提示；Safari 不一定允许锁定方向，不能依赖强制横屏 API。
- iPhone Safari 不能通过 Fullscreen API 隐藏地址栏；全屏游戏模式必须通过「分享 → 添加到主屏幕」以 PWA standalone 启动。
- 首次触摸后才能播放声音；不要设计自动播放 BGM。
- 触摸目标 ≥44×44 CSS px；琴键远大于此。
- 键盘区域设置 `touch-action:none`，避免 Safari 手势滚动/缩放干扰。
- 不开麦克风、不请求相机、不请求定位。
- 低电量模式、静音键、蓝牙耳机下都要能正常游玩。

## 3. 视觉方向

### 3.1 关键词

深夜舞台、霓虹琴键、圆角、轻量、糖果色点缀。不要拟物钢琴漆面，不要厚重金属，不要大量插画。

### 3.2 色板

| 用途 | 色值 |
| --- | --- |
| 背景 | `#0B0E17` |
| 面板 | `#171B2B` |
| 主色（青） | `#35E0D0` |
| 强调（珊瑚） | `#FF6B6B` |
| 金色/高分 | `#FFC857` |
| 主文字 | `#F5F7FF` |
| 次文字 | `#8A93B2` |
| 白键 | `#F7F9FF` |
| 黑键 | `#1A1F2E` |
| 成功 | `#5CE1A4` |
| 警告 | `#FFB020` |
| 错误 | `#FF5A6E` |

### 3.3 字体与字号

- 中文：iOS 系统字体 `PingFang SC`；英文/数字：`SF Pro Display` / 系统无衬线。
- 不使用需要授权的第三方字体。
- 956×440 画布建议字号：

| 层级 | 字号 | 字重 |
| --- | --- | --- |
| 页面主标题 | 28～32px | 700 |
| 卡片标题 | 18～20px | 600 |
| 正文 | 13～14px | 400 |
| 辅助文字 | 10～11px | 400 |
| 分数 | 22～24px | 700 |
| 判定字 | 24～28px | 800 |
| 琴键音名 | 12～14px | 600 |
| 按钮文字 | 14～16px | 600 |

- 正文不小于 13px；辅助文字不小于 10px；不要用 8px 小字。
- 数字使用等宽数字，分数滚动不跳动。

### 3.4 动效

| 动效 | 时长 |
| --- | --- |
| 按钮按下 | 70～100ms |
| 页面切换 | 180～220ms |
| 判定字出现 | 120ms，停留 400～500ms |
| Combo 跳变 | 120ms |
| 评级揭示 | 600～800ms |
| 分享卡生成 | ≤1.5s |

- 减少动效时只保留淡入/颜色变化，不做粒子、震动、翻转。
- 不使用全屏闪烁、快速缩放；闪烁频率 <3Hz。

## 7. 验收标准

### 7.1 设备与 Safari

- [ ] iPhone 16 Pro（874×402）Safari 横屏，页面不滚动、不裁切。
- [ ] iPhone 16 Pro Max（956×440）Safari 横屏，页面不滚动、不裁切。
- [ ] Safari 工具栏展开（约 956×352 / 874×314）时，键盘、判定线、主按钮仍完整可用。
- [ ] 左右 62px 安全区内无关键内容；不被 Dynamic Island / 圆角遮挡。
- [ ] 底部 21px 内无按钮、琴键、进度条；不被 Home Indicator 遮挡。
- [ ] 竖屏时只显示旋转提示，不显示错位游戏。
- [ ] 静音键、低电量模式、蓝牙耳机下可正常游玩。
- [ ] 首次触摸后音频正常，无自动播放报错。

### 7.2 视觉与交互

- [ ] 正文 ≥13px；辅助文字 ≥10px；琴键音名清晰。
- [ ] 所有可点区域 ≥44×44px；白键 ≥56px 宽。
- [ ] 判定字、Combo、分数在深色背景上对比度 ≥4.5:1。
- [ ] 白键/黑键、PERFECT/GREAT/GOOD/MISS 不只用颜色区分。
- [ ] 减少动效下仍可完整操作。
- [ ] 页面切换 ≤220ms，无白屏、无布局跳动。

### 7.3 图片

- [ ] 9 张源图齐备，尺寸、格式、命名符合第 4 章。
- [ ] 背景在 2622×1206 与 2868×1320 下裁切安全，无关键内容丢失。
- [ ] 6 张封面风格统一，无文字，圆形裁切不丢主体。
- [ ] 应用图标在 48×48 下可辨认。
- [ ] 首屏图片 ≤300KB；全部图片 ≤1MB。
- [ ] 透明素材无白边/黑边；图片内无多余文字。

### 7.4 音频

- [ ] 7 个音效无静音头、无爆音、无削波。
- [ ] 四类判定音可凭听感区分。
- [ ] 同类音效响度一致（±1 LU）。
- [ ] 外放、耳机各听一次，无异常刺耳。
