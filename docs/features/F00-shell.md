# F00 · 应用外壳与横屏框架

> **KeyTune · 键音 —— Play by Keys**
>
> KeyTune 是一款专为手机横屏设计的轻量音乐小游戏。玩家根据屏幕提示，在 15 键虚拟钢琴上按下对应琴键，跟随旋律完成演奏；系统用 PERFECT / GREAT / GOOD / MISS 判定每次按键，以 Combo、得分和评级给出即时反馈。你既可以跟着曲目挑战节奏，也可以自由弹奏、识别和弦，还能把整段演奏记录成可回放的作品。它不追求真实钢琴模拟，而是用「看得懂的音符 + 按得爽的琴键 + 停不下来的连击」，让任何人在 3 秒内上手、30 秒内完成第一段旋律。

## 1. Feature 概览

| 项目 | 内容 |
| --- | --- |
| 编号 | F00 |
| 阶段 | M1 能玩 |
| 优先级 | P0 |
| 依赖 | 无 |
| 被依赖 | F01～F13 |
| 一句话目标 | 建立可启动、可横屏、可导航、可保存设置的应用外壳，为所有玩法提供稳定入口 |
| 对应需求 | FR-01～FR-06、FR-130～FR-134、NFR-01、NFR-11、NFR-12 |

### 1.1 本 Feature 包含

- 启动加载与品牌露出。
- 横屏检测与旋转引导。
- 首页骨架：Logo、模式入口、曲库入口、我的演奏、成就、每日挑战、设置。
- 全局导航、返回、弹窗、确认框、Toast。
- 首次进入状态与“按 C”引导位（键盘由 F01 提供）。
- 设置页框架与本地档案的读写封装（音量、音色、判定、震动、动效、语言、数据管理）。
- 数据清除与版本/隐私说明。
- 全局异常兜底：加载失败、资源失败、存档异常。

### 1.2 本 Feature 不包含

- 琴键的绘制与发声（F01）。
- 具体音色与音量调节的听觉实现（F02）。
- 任何曲目、判定、计分、录制、成就逻辑（F03 以后）。

## 2. 用户故事

1. 作为第一次打开的玩家，我希望打开后不用注册、不用看教程，就知道这里可以按琴键。
2. 作为横屏玩家，我希望竖着拿手机时被温和提醒旋转，而不是看到错位界面。
3. 作为老玩家，我希望从首页最多点两下就能继续上次的曲目或进入自由演奏。
4. 作为谨慎的用户，我希望清除数据前被明确告知后果。
5. 作为离线用户，我希望没有网络也能进入首页和设置。

## 3. 业务流程

### 3.1 启动流程

```text
打开应用
  ↓
显示启动页（Logo + 进度）
  ├── 资源加载失败 → 显示“重试 / 离线进入”兜底页
  └── 加载完成
        ↓
读取本地档案
  ├── 首次进入 → 标记 firstRun，首页显示“按 C”呼吸提示
  ├── 档案损坏 → 使用默认设置，提示“部分数据已重置”
  └── 正常 → 恢复上次设置与最近曲目
        ↓
检测屏幕方向
  ├── 竖屏 → 旋转引导层
  └── 横屏 → 首页
```

### 3.2 首页导航流程

```text
首页
 ├── 快速开始 → 最近曲目 / 推荐 S01 → 曲目详情
 ├── 跟弹 → 曲库（筛选跟弹）→ 曲目详情
 ├── 节奏挑战 → 曲库（筛选节奏）→ 曲目详情
 ├── 闯关 → 闯关地图（P1 前显示“即将开放”）
 ├── 自由演奏 → 自由演奏页
 ├── 曲库 → 曲库页
 ├── 我的演奏 → 记录列表
 ├── 成就 → 成就页（P1 前显示占位）
 ├── 每日挑战 → 今日曲目（P2 前显示推荐曲目）
 └── 设置 → 设置页
```

### 3.3 首次进入流程

```text
首次进入首页
  ↓
中央键盘区域显示呼吸提示“按 C”
  ↓
用户按下 C（F01 提供发声）
  ↓
关闭提示，记录 firstNotePlayed
  ↓
显示“按 C 开始第一首”按钮 → S01 曲目详情
```

- 若用户 10 秒内未按键，提示保持呼吸但不弹窗。
- 用户可忽略提示，直接点击任意入口。

### 3.4 设置与数据清除流程

```text
设置
 ├── 声音：主音量 / 音乐 / 效果 / 音色 / 混响
 ├── 判定：严格度 / 音画校准
 ├── 体验：震动 / 减少动效 / 音名标签
 ├── 数据：占用空间 / 清除演奏记录 / 清除成绩与成就 / 清除全部
 └── 关于：版本号 / 隐私说明 / 素材版权
        ↓
点击清除
  ↓
二次确认弹窗（说明不可恢复）
  ↓
执行清除 → Toast“已清除” → 返回设置
```

## 4. 功能设计

### 4.1 启动页

- 全屏深色背景 + 居中 Logo + 底部细进度条。
- 加载超过 3 秒时，进度条下方显示一句轮换提示（如“准备琴键…”“调音中…”）。
- 加载失败显示“重新加载”和“离线进入”；离线进入只保证已缓存内容可用。
- 启动页不显示广告、不显示登录。

### 4.2 横屏引导

- 竖屏时显示全屏插画：手机旋转示意 + 文案“请横屏游玩”。
- 不弹系统全屏请求；不强制锁定方向（受平台限制时以提示为准）。
- 旋转为横屏后 1 秒内自动进入首页或恢复原页面。
- 游戏进行中旋转到竖屏：先暂停，再显示旋转引导；恢复横屏后停在暂停页。

### 4.3 首页布局

以 1920×1080 逻辑画布为例：

```text
┌──────────────────────────────────────────────────────────┐
│ Logo                          每日挑战   设置    ?       │  顶部 120px
├──────────────────────────────────────────────────────────┤
│                                                          │
│  继续演奏 / 快速开始                 模式入口             │
│  ┌────────────────────┐        ┌──────┐ ┌──────┐        │
│  │ 最近曲目封面        │        │ 跟弹 │ │ 节奏 │        │
│  │ 小星星 · 最佳 A     │        └──────┘ └──────┘        │
│  └────────────────────┘        ┌──────┐ ┌──────┐        │
│                                │ 闯关 │ │ 自由 │        │
│  曲库 →  我的演奏 →  成就 →      └──────┘ └──────┘        │
│                                                          │
│  ┌────────────────────────────────────────────────────┐  │
│  │ 15 键键盘预览（可按键发声，F01 提供）               │  │
│  └────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

- 顶部：Logo 左，功能图标右；图标均有文字标签或无障碍名称。
- 中部左：最近曲目卡片；无记录时显示推荐 S01。
- 中部右：四个模式入口，2×2 排列。
- 底部：键盘预览区，高度约 320px；首次进入显示“按 C”。
- 窄屏（<1280 逻辑宽）时，模式入口改为横向滚动，不压缩琴键。

### 4.4 全局导航

- 二级页面左上角返回箭头，点击返回上一级；首页无返回。
- 浏览器返回手势/按键与页面返回一致；游戏内返回先触发暂停确认。
- 页面切换 200ms 淡入/滑动，不阻塞输入。
- 导航状态在旋转、切后台后保持。

### 4.5 弹窗、确认与 Toast

| 类型 | 使用场景 | 规则 |
| --- | --- | --- |
| 信息弹窗 | 规则说明、隐私说明 | 单按钮“知道了” |
| 二次确认 | 删除记录、清空数据、退出游戏 | 主按钮为危险色；默认焦点在“取消” |
| 输入弹窗 | 重命名记录、分享昵称 | 1～20 字；空值禁用保存 |
| Toast | 保存成功、解锁、复制成功 | 1.5～2.5 秒自动消失；不遮挡琴键 |
| 全屏提示 | 旋转、加载失败 | 阻断操作，必须处理 |

### 4.6 设置页框架

| 分组 | 设置项 | 默认值 | 生效方式 |
| --- | --- | --- | --- |
| 声音 | 主音量 | 80 | 实时 |
| 声音 | 音乐音量 | 70 | 实时 |
| 声音 | 效果音量 | 80 | 实时 |
| 声音 | 音色 | Piano | 实时 |
| 声音 | 混响 | 低 | 实时 |
| 判定 | 严格度 | 标准 | 下一局 |
| 判定 | 音画校准 | 0ms | 实时 |
| 体验 | 震动 | 开 | 实时 |
| 体验 | 减少动效 | 关 | 实时 |
| 体验 | 音名标签 | 开 | 实时 |
| 数据 | 本地占用 | 只读 | 进入时刷新 |
| 数据 | 清除演奏记录 | — | 二次确认 |
| 数据 | 清除成绩与成就 | — | 二次确认 |
| 数据 | 清除全部数据 | — | 二次确认 |
| 关于 | 版本号 / 隐私说明 / 素材版权 | 只读 | — |

- F00 只搭框架与读写；F02 接入声音细节，F04 接入严格度，F10 接入记录清理。
- 任一设置修改后 300ms 内保存；保存失败 Toast 提示。

### 4.7 本地档案

- 保存键：设置、新手状态、最近曲目、曲目成绩、闯关进度、成就、演奏记录、每日挑战。
- 首次进入写入默认档案；版本升级时做字段补齐，不整包丢弃。
- 档案损坏：尽量按字段恢复；无法恢复的字段用默认值，并提示一次。
- 不保存任何设备唯一标识、位置、通讯录。

### 4.8 空状态与异常

| 场景 | 展示 |
| --- | --- |
| 无演奏记录 | 插画 + “还没有作品，去自由演奏弹一段” + 按钮 |
| 无成绩 | “完成一首曲目后，这里会出现你的最佳成绩” |
| 成就未开放（P1 前） | “成就系统正在调音中” |
| 曲库加载失败 | “曲库走丢了” + 重试 |
| 音频不可用 | “当前浏览器无法发声，请切换浏览器或检查静音” + 仍可浏览 |
| 存储不可用 | “无法保存进度” + 说明可能原因 + 重试 |

### 4.9 首次进入标记

- `firstRun`：是否首次进入。
- `firstNotePlayed`：是否按下第一个音。
- `firstSongCompleted`：是否完成第一首。
- 标记只用于引导与成就，不作为强制流程。

## 6. 界面与交互要求

- 首页所有可点元素有按下态（缩放 0.97 或亮度 +8%）。
- 琴键预览区不因导航动画位移。
- 顶部图标与底部模式卡片均支持单手拇指触达；关键按钮距屏幕边缘 ≥24px。
- 弹窗出现时背景压暗 60%，弹窗最大宽度 1200px，最大高度 800px。
- 文本不截断关键信息；曲名最多 2 行，超出省略。
- 所有图标配文字标签；纯图标按钮提供无障碍名称。
- 减少动效开启时，页面切换改为 100ms 淡入，取消位移动画。

## 7. 性能要求

| 指标 | 要求 |
| --- | --- |
| 冷启动到首页可交互 | ≤2.5 秒（4G 首次）；≤1.5 秒（缓存） |
| 首页首帧 | ≤1 秒内出现 Logo，不白屏 |
| 页面切换 | ≤200ms 可交互 |
| 设置保存 | ≤50ms 完成写入，不阻塞 UI |
| 内存 | 首页常驻 ≤120MB |
| 离线 | 首次加载后，首页、设置、已缓存玩法可离线进入 |
| 异常恢复 | 资源失败可重试；存档损坏不导致白屏 |

## 10. 预算与复用

- 图片：首屏 ≤300KB；全部 3 张打底图 ≤500KB。
- 音频：UI 音效 ≤30KB。
- 复用：15 张图与 7 个音效由全部 Feature 共用。

## 11. 风险与待确认

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 平台不允许强制横屏 | iOS 浏览器可能无法锁定方向 | 以插画引导为主，横屏后恢复状态 |
| 启动资源过多 | 首屏超过 2.5 秒 | 首屏只加载 Logo、背景、导航；其余懒加载 |
| 存档格式升级 | 后续字段增加 | 版本号 + 字段补齐；失败降级默认值 |
| 清除数据误操作 | 玩家丢失作品 | 二次确认 + 危险色 + 明确文案 |
| 首页信息过密 | 小屏拥挤 | 模式入口 2×2；窄屏横向滚动；琴键高度自适应 |
