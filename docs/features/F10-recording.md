# F10 · 演奏记录与回放

> **KeyTune · 键音 —— Play by Keys**
>
> KeyTune 是一款专为手机横屏设计的轻量音乐小游戏。玩家根据屏幕提示，在 15 键虚拟钢琴上按下对应琴键，跟随旋律完成演奏；系统用 PERFECT / GREAT / GOOD / MISS 判定每次按键，以 Combo、得分和评级给出即时反馈。你既可以跟着曲目挑战节奏，也可以自由弹奏、识别和弦，还能把整段演奏记录成可回放的作品。它不追求真实钢琴模拟，而是用「看得懂的音符 + 按得爽的琴键 + 停不下来的连击」，让任何人在 3 秒内上手、30 秒内完成第一段旋律。

---

## 1. Feature 概览

| 项目 | 内容 |
| --- | --- |
| 编号 | F10 |
| 阶段 | M3 有作品感 |
| 优先级 | P0 |
| 依赖 | F01、F09 |
| 被依赖 | F11 |
| 一句话目标 | 把一次演奏变成一条几 KB 的作品，能保存、能重命名、能原样回放 |
| 对应需求 | FR-100～FR-108、10.2、7.6 |

### 1.1 本 Feature 包含

- 演奏事件录制：按下/松开、音名、时间、音色。
- 录制倒计时、状态、时长上限、自动停止。
- 保存、试听、重录、丢弃。
- 我的演奏列表：排序、封面/波形、统计、播放、重命名、删除。
- 回放：进度条、暂停、继续、停止、拖动、琴键高亮、音色还原。
- 从结算页保存本局演奏。
- 本地存储上限与超限处理。

### 1.2 本 Feature 不包含

- 麦克风录音、音频文件录制（P2，且命名上严格区分）。
- 对事件进行音符级编辑（首版只支持重命名与删除；裁剪/合并为 P2）。
- 云同步、分享链接（P2）。

## 2. 用户故事

1. 作为玩家，我随手弹了一段，希望点一下就能录下来。
2. 作为玩家，我希望录下来的东西很小，不占空间。
3. 作为玩家，我希望回放时听到的和当时弹的一模一样，包括节奏和音色。
4. 作为玩家，我希望给作品起个名字，之后能认出来。
5. 作为玩家，我希望删除前被确认，不要误删。

## 3. 业务流程

### 3.1 录制流程

```text
自由演奏 / 结算页 → 录制
  ↓
检查是否已有未保存录音
  ├── 有 → 提示“继续录制会丢弃当前未保存内容”
  └── 无 → 继续
  ↓
3-2-1 倒数（可关闭）
  ↓
开始计时，记录事件
  ↓
演奏（可切换音色、开关节拍器）
  ↓
点击停止 / 到达 5 分钟
  ↓
试听（可选）→ 保存 / 重录 / 丢弃
  ↓
输入标题 → 保存 → 我的演奏
```

### 3.2 回放流程

```text
我的演奏 → 选择记录 → 播放
  ↓
3 秒准备（可选关闭）
  ↓
按原始时间触发事件：按下发声 + 键帽高亮；松开停声
  ↓
进度条推进，可暂停/继续/停止/拖动
  ↓
结束 → 回到记录详情/列表
```

### 3.3 重命名与删除

```text
记录详情 → 重命名
  ↓
输入 1～20 字
  ↓
保存 → 列表即时更新

记录详情 → 删除
  ↓
二次确认（说明不可恢复）
  ↓
删除 → 返回列表 → Toast“已删除”
```

### 3.4 从结算保存

```text
结算页 → 保存演奏
  ↓
自动生成标题（曲名 · 模式 · 日期时间）
  ↓
保存事件 + 本局统计
  ↓
Toast“已保存到我的演奏”
```

## 4. 功能设计

### 4.1 事件模型

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| note | 音名，如 C4 | 15 键之一 |
| type | down / up | 必填 |
| time | 相对录制开始的毫秒 | 0～300000，升序 |
| velocity | 力度 | 0.1～1.0，可选，默认 0.8 |
| timbre | 该事件使用的音色 | 仅 down 事件需要；音色变化时记录 |

记录头：

| 字段 | 说明 |
| --- | --- |
| id | 唯一标识 |
| title | 1～20 字 |
| createdAt | 创建时间 |
| duration | 总时长 ms |
| timbre | 初始音色 |
| source | free / follow / rhythm |
| songId | 来源曲目，自由演奏为空 |
| events | 事件数组 |
| stats | 来源为游戏时的分数、准确率、Combo |

规则：

- 同一时刻允许多个 down（和弦）。
- 每个 down 必须有对应的 up；录制结束时仍未松开的音，自动在结束时刻补 up。
- 事件按时间升序；同一时间按按下顺序排列。
- 音色变化记录在 down 事件上，回放时切换。
- 不记录节拍器、UI 音效、环境音。
- 不记录判定结果（判定统计单独存于 stats）。

### 4.2 录制规则

| 项目 | 规则 |
| --- | --- |
| 开始 | 3-2-1 倒数后开始，倒数不计入时长 |
| 时长上限 | 5 分钟（300000ms） |
| 上限前提示 | 剩余 30 秒 |
| 到达上限 | 自动停止，进入保存流程 |
| 最短有效 | 至少 1 个 down 事件，且时长 ≥500ms |
| 录制中切后台 | 自动停止并保留，提示保存/丢弃 |
| 录制中退出 | 二次确认；可保存或丢弃 |
| 录制中切换音色 | 允许，记录音色变化 |
| 录制中开启节拍器 | 允许，节拍器不录入 |
| 重复录制 | 新录制覆盖未保存内容前需确认 |

- 录制状态在顶部明显显示：红点 + 计时 + “停止”。
- 录制中不做判定、不显示分数。
- 录制中按键延迟与自由演奏一致，不因录制增加延迟。

### 4.3 保存流程

```text
停止
  ↓
生成试听（可选，直接回放最后 10 秒或全曲）
  ↓
保存面板：
  ├── 标题输入（默认“我的演奏 MM-DD HH:mm”）
  ├── 时长、音符数、音色
  ├── [保存] [重录] [丢弃]
  ↓
保存 → 写入本地 → 成功 Toast
```

- 标题为空时禁用保存；自动去除首尾空格。
- 重名允许，用 id 区分。
- 保存失败：提示“存储空间不足，请删除旧作品后重试”，保留当前数据。
- 保存成功后清空录制缓冲，避免重复保存。

### 4.4 我的演奏列表

布局：

```text
┌──────────────────────────────────────────────────────────┐
│ ← 我的演奏                              共 8 条  占 42KB  │
│                                                          │
│ ┌──────────────────────────────────────────────────────┐ │
│ │ ▷  我的第一首歌            00:24   12 个音  10-30    │ │
│ │    小星星 · 节奏挑战 · 96% · Combo 24                │ │
│ └──────────────────────────────────────────────────────┘ │
│ ┌──────────────────────────────────────────────────────┐ │
│ │ ▷  随手弹的 C 和弦         00:08   6 个音   10-29    │ │
│ │    自由演奏 · Piano                                  │ │
│ └──────────────────────────────────────────────────────┘ │
│                                                          │
│ [ + 去自由演奏 ]                                         │
└──────────────────────────────────────────────────────────┘
```

- 按创建时间倒序，最新在上。
- 每条显示：播放按钮、标题、时长、音符数、来源、日期、成绩摘要。
- 记录卡片可点击进入详情；播放按钮直接播放。
- 顶部显示总数与占用空间。
- 列表为空：插画 + “还没有作品，去自由演奏弹一段” + 按钮。
- 支持滚动；超过 20 条时禁止新建，提示删除旧作品。

### 4.5 记录详情

- 标题、创建时间、时长、音符数、来源、音色。
- 若来源为游戏：分数、准确率、最大 Combo、评级。
- 操作：播放、重命名、删除、返回。
- 波形缩略图：根据事件密度生成，仅作视觉，不要求精确。
- 不提供音符级编辑（首版）；“编辑”即重命名。

### 4.6 回放规则

| 项目 | 规则 |
| --- | --- |
| 准备 | 3 秒倒计时（可在设置关闭） |
| 时间基准 | 记录中的相对时间 |
| 音色 | 按事件中的音色还原，允许与当前设置不同 |
| 音量 | 使用当前音量设置 |
| 键帽高亮 | 按下高亮，松开取消；和弦多键同时高亮 |
| 进度条 | 显示当前时间 / 总时长，可拖动 |
| 暂停 | 暂停计时与发声；继续时 1 秒准备 |
| 停止 | 立即停止，回到 0 |
| 拖动 | 释放后从目标时间继续；已按下的音先释放再重建 |
| 结束 | 最后一个事件后 500ms 停止，显示“播放结束” |
| 循环 | 首版不循环 |

- 回放不产生判定、分数、Combo。
- 回放中键盘为只读，玩家按键不发声、不打断回放。
- 回放中可调节音量；切换音色无效（以记录为准）。
- 切后台自动暂停；回前台不自动继续。

### 4.7 删除与存储限制

| 项目 | 规则 |
| --- | --- |
| 删除确认 | 二次确认，说明不可恢复 |
| 批量删除 | 首版不做 |
| 单条上限 | 5 分钟 |
| 条数上限 | 20 条 |
| 总占用上限 | 2MB |
| 超限 | 禁止新建，提示删除旧作品 |
| 单条大小 | 通常 <20KB；复杂演奏 <100KB |
| 清除全部 | 设置 → 数据管理，需二次确认 |

- 删除后立即释放空间，列表刷新。
- 存储失败不静默；提示原因与建议。
- 记录损坏：跳过该条并提示“1 条作品无法读取”，不影响其他记录。

### 4.8 从游戏结算保存

- 只保存本局实际按键事件；未按下的目标音符不生成事件。
- 保存标题默认“曲名 · 模式 · MM-DD HH:mm”。
- stats 保存本局分数、准确率、最大 Combo、评级。
- 若本局无有效按键，禁用保存。
- 保存后按钮变为“已保存”，不可重复保存。
- 从结算保存的记录与自由演奏记录同一列表、同一上限。

### 4.9 与麦克风录音的区分

- 本 Feature 统一称“演奏记录”或“演奏”，不称“录音”。
- 分享、列表、按钮文案避免“录音”二字。
- 未来麦克风录音单独命名“音频录音”，单独入口、单独列表、单独权限说明。
- 首版不申请麦克风权限。

## 6. 界面与交互要求

- 录制按钮在自由演奏顶部右侧，直径 ≥96px。
- 录制中红点脉冲频率 ≤1Hz，避免焦虑。
- 我的演奏列表卡片高度 ≥160px，播放按钮 ≥64×64。
- 回放进度条高度 ≥12px，拖拽点 ≥44×44。
- 回放时键盘高亮与声音同步，偏差 ≤30ms。
- 删除确认的主按钮为危险色，默认焦点在“取消”。
- 回放中返回需确认停止。
- 减少动效时，取消红点脉冲与波形动画，保留状态文字。

## 7. 性能要求

| 指标 | 要求 |
| --- | --- |
| 录制按键延迟 | 与自由演奏一致，≤50ms（P95） |
| 事件写入 | 不阻塞演奏；每 100ms 批量落盘 |
| 回放同步 | 声音与高亮偏差 ≤30ms |
| 回放拖动 | 释放后 ≤200ms 恢复 |
| 列表加载 | 20 条 ≤300ms |
| 内存 | 录制 5 分钟增量 ≤10MB |
| 存储 | 单条 <100KB；20 条 <2MB |
| 崩溃恢复 | 已保存记录不丢失；录制中崩溃最多丢最后 1 秒 |

## 11. 风险与待确认

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 事件时间漂移 | 回放节奏不准 | 以单调时钟计时；每 100ms 落盘；长录音测试 |
| 录制中崩溃 | 丢失作品 | 每 100ms 落盘；最多丢 1 秒 |
| 存储不足 | 无法保存 | 提前展示占用；超限提示删除；单条 <100KB |
| 回放拖动爆音 | 快速跳转 | 先释放所有音，再重建 |
| 音色记录复杂 | 回放不一致 | 每个 down 事件记录音色；变化点明确 |
| “录音”歧义 | 用户以为录麦克风 | 全文使用“演奏记录”；麦克风功能单独命名 |
| 20 条上限 | 重度用户不够 | 首版限制；P2 提供导出/扩容 |
