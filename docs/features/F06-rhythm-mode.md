# F06 · 节奏挑战模式

> **KeyTune · 键音 —— Play by Keys**
>
> KeyTune 是一款专为手机横屏设计的轻量音乐小游戏。玩家根据屏幕提示，在 15 键虚拟钢琴上按下对应琴键，跟随旋律完成演奏；系统用 PERFECT / GREAT / GOOD / MISS 判定每次按键，以 Combo、得分和评级给出即时反馈。你既可以跟着曲目挑战节奏，也可以自由弹奏、识别和弦，还能把整段演奏记录成可回放的作品。它不追求真实钢琴模拟，而是用「看得懂的音符 + 按得爽的琴键 + 停不下来的连击」，让任何人在 3 秒内上手、30 秒内完成第一段旋律。

## 1. Feature 概览

| 项目 | 内容 |
| --- | --- |
| 编号 | F06 |
| 阶段 | M2 有游戏感 |
| 优先级 | P0 |
| 依赖 | F01、F03、F04 |
| 被依赖 | F07、F08 |
| 一句话目标 | 让音符从上方落下，玩家在判定线按键，完整体验“音乐 + 判定 + Combo”的游戏感 |
| 对应需求 | FR-50～FR-58、7.4、9.3 |

### 1.1 本 Feature 包含

- 下落音符轨道、判定线、音符与琴键的对齐。
- 下落速度三档、倒计时、进度、暂停。
- 单音与和弦音符的呈现。
- 命中、漏音、空击的视觉反馈。
- 曲目背景与氛围层。
- 长音与滑奏的呈现规则预留（P1 实现）。
- 完成后交给 F07 结算。

### 1.2 本 Feature 不包含

- 判定窗口与分数算法（F04）。
- 结算页（F07）。
- 闯关编排（F08）。
- 曲目选择与谱面内容（F03）。

## 2. 用户故事

1. 作为玩家，我希望音符落下来时，一眼看出该按哪个键。
2. 作为玩家，我希望在判定线附近按键时有明确反馈，而不是按了没反应。
3. 作为玩家，我希望连续命中时 Combo 和分数不断增长，有爽感。
4. 作为玩家，我希望漏音不会让歌曲中断，可以继续完成。
5. 作为玩家，我希望暂停后能从容继续，不用从头再来。

## 3. 业务流程

### 3.1 进入与准备

```text
曲目详情 → 节奏挑战
  ↓
准备页：音色、下落速度（慢/标准/快）、严格度
  ↓
点击开始
  ↓
加载曲目（≤500ms）
  ↓
3-2-1 倒计时（每拍一次，最后一拍后立即开始）
  ↓
第一音进入轨道
```

### 3.2 游戏循环

```text
每一帧
  ↓
根据当前时间计算每个音符的纵向位置
  ↓
音符从轨道顶部向下移动
  ↓
到达判定线附近 → 高亮对应琴键/轨道
  ↓
玩家按键
  ├── 匹配成功 → F04 判定 → 判定字 + 特效 + 音效
  ├── 音高错误 → 空击反馈，不消耗音符
  └── 无输入 → 音符越过判定线 + GOOD 窗口 → MISS
  ↓
更新 Combo、分数、进度
  ↓
曲目结束 → 结算
```

### 3.3 暂停与继续

```text
点击暂停 / 切后台
  ↓
冻结时间轴、停止伴奏、释放所有音
  ↓
暂停页：继续 / 重开 / 退出 / 音量
  ↓
继续 → 3-2-1 倒计时（不重复曲目开头）
  ↓
从暂停点继续
```

### 3.4 曲目结束

```text
最后一个音符判定完成 + 2 秒
  ↓
停止伴奏（淡出 500ms）
  ↓
显示“完成”过场
  ↓
交给 F07 结算
```

## 4. 功能设计

### 4.1 轨道布局

以 1920×1080 逻辑画布为例：

```text
┌──────────────────────────────────────────────────────┐
│ ← 暂停   小星星    ─────────●──────── 42%   12,340   │
│                                                      │
│          ◆        ◆                                  │
│              ◆                                       │
│        ◆                  ◆                          │
│                                                      │
│  ══════════════════════════════════════════════════  │ ← 判定线
│  ┌──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┐    │
│  │C │D │E │F │G │A │B │C │D │E │  ... 15 键    │    │
│  └──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┘    │
└──────────────────────────────────────────────────────┘
```

- 15 个音符轨道与 15 个琴键一一对齐，轨道宽度 = 对应琴键宽度。
- 白键轨道与白键同宽；黑键音符悬浮于两白键之间，轨道窄，音符略小。
- 判定线位于键盘上沿上方 80px，横贯屏幕。
- 音符从判定线上方进入，向下落至判定线。
- 判定线以下不显示音符；MISS 后音符 200ms 内淡出。

### 4.2 音符视觉

| 类型 | 外观 | 尺寸 | 说明 |
| --- | --- | --- | --- |
| 白键单音 | 青蓝圆角长条 + 音名 | 96×144 | 与白键轨道居中对齐 |
| 黑键单音 | 珊瑚圆角长条 + 升号名 | 72×120 | 位于两白键之间 |
| 和弦 | 叠层卡片 + 音数角标 | 96×144（叠 3 层） | 显示“3”角标；颜色偏金 |
| 长音（P1） | 头部 + 拉伸尾条 | 96×可变 | 按住期间尾条缩短 |
| 滑奏（P1） | 斜向连串小音符 | 64×64/个 | 连续快速触发 |

- 音符内部显示音名（C、C#），字号 28px；黑键音符字号 22px。
- 音符边缘发光，颜色与音高类别一致；不依赖颜色区分音名。
- 同一轨道连续音符之间至少留 8px 间隙。
- 和弦音符不拆成多个下落物，避免视觉混乱。

### 4.3 下落速度

| 档位 | 视觉提前量 | 适用 |
| --- | --- | --- |
| 慢 | 约 1600ms（2.67 拍 @100BPM） | 新手 |
| 标准 | 约 1200ms（2 拍 @100BPM） | 默认 |
| 快 | 约 900ms | 有经验玩家 |

- 速度只改变音符在屏幕上的移动速度，不改变谱面时间与判定窗口。
- 速度切换仅在准备页；局中不可改。
- 音符位置 = 判定线位置 - (目标时间 - 当前时间) / 提前量 × 轨道可视高度。
- 当前时间超过目标时间后，音符继续下落并在 MISS 后淡出。

### 4.4 判定线

- 判定线为 8px 高青色光带，命中时局部增亮 300ms。
- 判定线不随音符移动，不 blinking。
- 判定文字出现在判定线上方 120px，向上飘。
- 判定线下方 0～80px 为琴键触发区，玩家点击琴键即按键，不需要点判定线。

### 4.5 轨道高亮与引导

- 音符进入判定线前 400ms，对应琴键边缘开始发光。
- 音符到达判定线时，琴键发光最强。
- 多个音符接近时，只高亮最近的一个；和弦高亮所有相关键。
- 高亮不改变琴键按下态；玩家按下后叠加按下态。
- 减少动效时，取消脉冲，保留常亮高亮。

### 4.6 倒计时与开始

- 3-2-1 各 1 拍，字号 160px，居中偏上。
- 每拍有节拍声与视觉缩放；第三拍后 0ms 开始第一音。
- 倒计时期间按键不判定、不计分，但可发声（用于试手）。
- 倒计时可点击跳过（直接开始），仅限准备页设置中开启。

### 4.7 进度与 HUD

| 元素 | 位置 | 内容 |
| --- | --- | --- |
| 暂停 | 左上 | 64×64 图标 |
| 曲名 | 左上偏右 | 最多 12 字 |
| 进度条 | 顶部中央 | 当前时间 / 总时长 |
| 分数 | 右上 | 滚动数字，千分位 |
| Combo | 屏幕中上 | 数字 + 火焰；0 时隐藏 |
| 判定字 | 判定线上方 | PERFECT / GREAT / GOOD / MISS |
| 准确率（可选） | 右上角小字 | 实时百分比，默认关闭 |

- HUD 不遮挡轨道与音符。
- 分数变化使用 200ms 滚动，不跳变。
- Combo 归零时数字缩小淡出，不播放刺眼动画。

### 4.8 和弦与多押

- 和弦作为一个音符块下落，块上显示音数。
- 到达判定线时，需要按齐所有目标音；判定由 F04 处理。
- 和弦块命中后，所有相关琴键同时发光。
- 和弦块漏音时，整组 MISS，块整体淡出。
- 同一时刻最多 3 音和弦（首版）。

### 4.9 长音与滑奏（P1 预留）

- 长音：头部到达判定线时按下，尾条随进度缩短；松开过早按 F04 规则判定。
- 滑奏：一串小音符沿轨道斜向排列，按顺序触发，不要求精确按住。
- 首版谱面不包含长音与滑奏；轨道与渲染需预留空间，不出现布局跳变。

### 4.10 背景与氛围

- 每首曲目一张主题背景，暗色、低对比，不干扰音符。
- 背景可有缓慢呼吸/粒子，但每秒变化不超过 2 次，避免视觉疲劳。
- 命中 50 Combo 时背景轻微脉冲一次；减少动效时取消。
- 背景不包含高亮文字、快速闪烁。

### 4.11 MISS 与空击

- 音符越过判定线 + GOOD 窗口 → MISS，音符变灰并淡出。
- 空击：按到没有目标的键，键帽正常按下态，但不产生判定字；标准模式不扣分、不断 Combo。
- 连续空击 5 次：显示一次轻提示“看准再按”，不重复刷屏。
- 严格模式（P1）：空击断 Combo，屏幕边缘轻微红闪。

## 6. 界面与交互要求

- 音符与琴键必须严格对齐；不同屏幕比例下仍保持一一对应。
- 判定线不被 Combo、判定字、弹窗遮挡。
- 琴键按下区域包含整个键帽，不需要点轨道。
- 顶部 HUD 与键盘之间至少保留 2 个音符高度的净空。
- 黑键音符不遮住白键音名。
- 暂停按钮避开右手主要演奏区。
- 减少动效时，取消背景脉冲、粒子、判定线闪烁，保留判定文字。
- 强光环境下音符与背景对比度 ≥4.5:1。

## 7. 性能要求

| 指标 | 要求 |
| --- | --- |
| 进入游戏 | ≤800ms |
| 帧率 | 60fps；95% 帧 ≥45fps；无 >100ms 卡顿 |
| 音符位置精度 | 与目标时间偏差 ≤±15ms |
| 同屏音符 | 30 个不重叠、不卡顿 |
| 输入延迟 | 触感到判定 ≤1 帧 |
| 长曲 | 5 分钟无累计漂移 |
| 内存 | 单局增长 ≤20MB |
| 降级 | 低端设备可减少粒子与背景动效，不影响判定 |

## 11. 风险与待确认

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 15 轨过密 | 音符重叠、误读 | 黑键音符变窄；同轨间隙；和弦不拆块 |
| 下落速度不适 | 新手看不清 | 三档速度；默认标准 |
| 伴奏与按键冲突 | 声音浑浊 | 伴奏不含主旋律；响度平衡 |
| 判定线被遮挡 | 手感差 | HUD 固定区域；特效限高 |
| 长曲漂移 | 后半段不准 | 音频时钟；每局校准；长曲测试 |
| 低端机掉帧 | 音符跳动 | 降级粒子/背景；保证判定独立于渲染 |
| 曲目背景过多 | 包体大 | 6 张主题背景懒加载；通用背景兜底 |
