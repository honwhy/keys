# F13 · 体验打磨与发布

> **KeyTune · 键音 —— Play by Keys**
>
> KeyTune 是一款专为手机横屏设计的轻量音乐小游戏。玩家根据屏幕提示，在 15 键虚拟钢琴上按下对应琴键，跟随旋律完成演奏；系统用 PERFECT / GREAT / GOOD / MISS 判定每次按键，以 Combo、得分和评级给出即时反馈。你既可以跟着曲目挑战节奏，也可以自由弹奏、识别和弦，还能把整段演奏记录成可回放的作品。它不追求真实钢琴模拟，而是用「看得懂的音符 + 按得爽的琴键 + 停不下来的连击」，让任何人在 3 秒内上手、30 秒内完成第一段旋律。

## 3. 业务流程

### 3.1 性能打磨流程

```text
基线测量（目标机型）
  ↓
找出超标项
  ├── 启动慢 → 首屏资源瘦身、延迟加载
  ├── 帧率低 → 降低粒子/背景动效、合并绘制
  ├── 延迟高 → 起音优化、校准、减少音频链路
  ├── 内存高 → 释放曲目资源、限制缓存
  └── 包体大 → 图片压缩、音频按需加载
  ↓
复测 → 达标 → 锁定
```

### 3.2 兼容性验证流程

```text
设备矩阵
  ├── iOS Safari（刘海/无刘海各 1）
  ├── Android Chrome（高/中/低端各 1）
  ├── 微信内置浏览器（iOS/Android 各 1）
  └── 桌面 Chrome/Edge（鼠标+键盘）
  ↓
逐项跑核心路径
  ↓
记录问题 → 修复 → 回归
```

### 3.3 发布前检查

```text
功能回归 → 性能复测 → 素材检查 → 隐私检查 → 发布物料 → 上线
```

## 4. 功能设计

### 4.1 性能达标

| 指标 | 目标 | 测量方法 |
| --- | --- | --- |
| 冷启动可交互 | ≤2.5s | 4G、清缓存、中端机、3 次取中位 |
| 缓存后启动 | ≤1.5s | 二次启动 |
| 首页→游戏 | ≤800ms | 点击到可操作 |
| 触感→发声 | P95 ≤50ms | 高速摄像/音频回环，30 次 |
| 触感→视觉 | ≤16.7ms | 录屏逐帧 |
| 帧率 | 60fps，95% ≥45fps | 游戏内 60 秒采样 |
| 判定精度 | ±15ms | 已知节拍点击测试 |
| 内存峰值 | ≤200MB | 连续 3 首 |
| 30 分钟耗电 | ≤10% | 中端机、50% 亮度、60% 音量 |
| 首屏资源 | ≤1.5MB | 网络面板/包体 |
| 完整初始包 | ≤3MB | 包体 |

- 任一指标不达标，必须记录原因、影响与豁免人。
- 低端设备允许降级：关闭粒子、背景动效、混响；判定与发声不得降级。
- 性能测试至少覆盖 3 台真机，不用模拟器代替。

### 4.2 兼容性矩阵

| 平台 | 最低版本 | 必测机型/环境 | 重点 |
| --- | --- | --- | --- |
| iOS Safari | iOS 15+ | iPhone 11、iPhone 14 Pro（刘海/灵动岛） | 横屏、安全区、音频解锁、静音键 |
| Android Chrome | Android 10+ | 中端 2022、低端 2020、旗舰 2023 | 多指、延迟、返回键 |
| 微信 iOS | 最新 | iPhone 13 | 音频、横屏、分享 |
| 微信 Android | 最新 | 中端机 | X5/XWeb 音频、触摸 |
| 桌面 Chrome | 最新两个大版本 | 1920×1080 | 鼠标、键盘映射、窗口缩放 |
| 桌面 Edge | 最新两个大版本 | 1920×1080 | 同上 |

- 16:9、19.5:9、20:9、21:9 各至少 1 台。
- 刘海/挖孔/圆角/手势条必须验证。
- 蓝牙耳机、有线耳机、外放各验证一次延迟与校准。
- 系统深色/浅色模式不改变游戏视觉（固定深色）。

### 4.3 交互打磨

| 项目 | 要求 |
| --- | --- |
| 加载 | 首屏 Logo + 进度；>3s 显示调音文案；失败可重试 |
| 页面切换 | 200ms；不阻塞输入 |
| 按钮反馈 | 按下缩放 0.97 / 亮度 +8%；释放回弹 |
| 震动 | 仅 Combo 里程碑、错误、结算；可关；单次 ≤50ms |
| 音效 | 统一响度；不叠加成噪音；可分别调音量 |
| 错误提示 | 说人话、给下一步；不出现代码/英文报错 |
| 空状态 | 插画 + 一句说明 + 一个行动按钮 |
| 网络 | 核心玩法不依赖网络；无网络时不显示报错 |
| 返回 | 游戏内先暂停；删除先确认；录制中先确认 |
| 首帧 | 不出现白屏、布局跳动、字体闪烁 |

### 4.4 无障碍

| 项目 | 要求 |
| --- | --- |
| 对比度 | 文字/背景 ≥4.5:1；大字 ≥3:1 |
| 触控目标 | 主要按钮 ≥44×44；琴键远大于此 |
| 色弱 | 判定/星级/状态不只靠颜色；加文字/形状 |
| 减少动效 | 关闭粒子、震动、翻转、背景脉冲；保留淡入 |
| 震动开关 | 独立开关；关闭后完全不震动 |
| 音名标签 | 可关闭；关闭后仍有按下浮字 |
| 无障碍名称 | 所有图标按钮有可读名称 |
| 键盘操作 | 桌面端 Tab 可聚焦主要按钮，Enter 触发 |
| 字体缩放 | 系统字体放大 120% 不截断关键信息 |
| 晕动症 | 不使用全屏快速缩放、旋转、闪烁（>3Hz） |

### 4.5 音频最终混音

- 所有音效统一到 -14 LUFS（短音效），峰值 ≤-3dBFS。
- 所有 BGM 统一到 -16 LUFS，峰值 ≤-1dBTP。
- 切换曲目/音色不出现响度跳变。
- 按键声、伴奏、判定音效三者平衡：
  - 按键声清晰可辨；
  - 伴奏不盖过按键；
  - 判定音效不刺耳。
- 所有循环点无爆音、无节奏断点。
- 所有音效头尾去静音；结尾 5～20ms 淡出。
- 提供“最终混音检查表”，逐项签字。

- 截图必须使用真实游戏画面，不伪造分数与评级。
- 截图中不出现真实用户信息。

### 4.7 回归测试清单

- 首次进入 → 按 C → 发声 → 进入 S01 → 完成 → 结算 → 再来一次。
- 曲库 6 首 → 每首跟弹/节奏各完成一次。
- 自由演奏 → C/E/G → 识别 → 录制 → 保存 → 回放 → 重命名 → 删除。
- 50 Combo → 成就 → 成就页。
- 闯关 1-1 → 1 星 → 解锁 1-2 → 第一章完成。
- 每日挑战 → 完成 → 今日最佳 → 分享卡片。
- 设置改音色/音量/严格度/校准 → 刷新 → 保持。
- 切后台/来电/锁屏/旋转/断网/清缓存。
- 删除全部数据 → 回到首次状态。
- 减少动效/关震动/静音 → 全流程可用。
