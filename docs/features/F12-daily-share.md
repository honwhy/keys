# F12 · 每日挑战与分享

> **KeyTune · 键音 —— Play by Keys**
>
> KeyTune 是一款专为手机横屏设计的轻量音乐小游戏。玩家根据屏幕提示，在 15 键虚拟钢琴上按下对应琴键，跟随旋律完成演奏；系统用 PERFECT / GREAT / GOOD / MISS 判定每次按键，以 Combo、得分和评级给出即时反馈。你既可以跟着曲目挑战节奏，也可以自由弹奏、识别和弦，还能把整段演奏记录成可回放的作品。它不追求真实钢琴模拟，而是用「看得懂的音符 + 按得爽的琴键 + 停不下来的连击」，让任何人在 3 秒内上手、30 秒内完成第一段旋律。

## 1. Feature 概览

| 项目 | 内容 |
| --- | --- |
| 编号 | F12 |
| 阶段 | M5 可传播 |
| 优先级 | P2 |
| 依赖 | F03、F07、F11 |
| 被依赖 | 无 |
| 一句话目标 | 每天给玩家一个回来的理由，并让一次好成绩能被保存成一张愿意发出去的卡片 |
| 对应需求 | FR-120～FR-124、9.10、7.8 |

### 1.1 本 Feature 包含

- 每日 00:00（本地时间）刷新“今日曲目”。
- 今日曲目选择规则（离线、确定性）。
- 今日最佳、连续参与天数、完成状态。
- 每日挑战入口与结算对接。
- 成绩分享卡片：预览、昵称、保存图片、系统分享。
- 分享卡片的两种比例与隐私规则。

### 1.2 本 Feature 不包含

- 服务器、全球排行榜、好友系统。
- 分享链接、动态页面、邀请奖励。
- 用户头像上传、社交账号绑定。
- 麦克风录音分享。

## 3. 业务流程

### 3.1 每日刷新

```text
打开应用 / 进入首页 / 进入每日挑战
  ↓
读取本地日期 YYYY-MM-DD
  ↓
与 lastDailyDate 比较
  ├── 相同 → 保持今日曲目与成绩
  └── 不同 → 生成新今日曲目
        ↓
     从已解锁曲库中按日期种子选 1 首
        ↓
     清空“今日最佳”（历史连续天数保留）
        ↓
     更新 lastDailyDate
```

### 3.2 每日挑战

```text
首页 → 每日挑战
  ↓
展示今日曲目、封面、难度、今日最佳、连续天数
  ↓
点击“开始挑战”
  ↓
按节奏挑战模式进入（F06）
  ↓
完成 → 结算（F07）
  ↓
若分数 > 今日最佳 → 更新
  ↓
当日首次完成 → 连续天数 +1
  ↓
可再次挑战，取最高
```

### 3.3 分享流程

```text
结算页 / 每日挑战页 → 分享
  ↓
打开分享预览
  ├── 选择比例：竖版 1080×1920 / 横版 1200×630
  ├── 可选输入昵称（1～12 字，默认“匿名演奏者”）
  └── 预览卡片
        ↓
   保存图片 / 系统分享
        ↓
   成功 Toast / 失败降级提示
```

## 4. 功能设计

### 4.1 今日曲目选择

- 种子 = 本地日期字符串 `YYYY-MM-DD`。
- 候选池 = 当前已解锁的曲库曲目（不含练习关卡）。
- 选择方式必须稳定：同一天、同一设备、同一曲库状态，结果一致。
- 不依赖网络、不请求服务器。
- 若候选池为空（异常），回退到 S01。
- 曲目在当天 00:00 前不变；跨天后首次进入时刷新。
- 不做“刷新换一首”，避免刷题。

示例（概念）：

```text
候选池按 id 排序 → 取日期哈希 → 对池长度取模 → 选中曲目
```

### 4.2 每日挑战页

```text
┌──────────────────────────────────────────────────────────┐
│ ← 每日挑战                        连续 3 天 🔥            │
│                                                          │
│  ┌──────────────┐   今日曲目                             │
│  │              │   小星星                               │
│  │    封面      │   入门 · Lv2 · 100 BPM · 32 秒         │
│  │              │                                        │
│  └──────────────┘   今日最佳：2,380 · A                   │
│                     完成次数：2                           │
│                                                          │
│  [ 开始挑战 ]                    [ 分享今日成绩 ]         │
│                                                          │
│  今日剩余：无限次，取最高分                               │
└──────────────────────────────────────────────────────────┘
```

- 顶部显示连续参与天数；未参与显示“今天还没挑战”。
- 今日最佳无记录时显示“—”。
- 开始挑战使用当前音色、严格度、校准；速度固定标准。
- 完成后回到每日挑战页，今日最佳即时更新。
- 分享按钮在无成绩时禁用。

### 4.3 连续参与

| 情况 | 连续天数 |
| --- | --- |
| 首次完成 | 1 |
| 昨天完成、今天完成 | +1 |
| 今天完成多次 | 不重复 +1 |
| 中断 1 天及以上 | 归 1 |
| 只打开未完成 | 不变 |

- 以本地日期计算，跨时区旅行按设备本地日期。
- 连续天数只增不减（当天内），跨天中断才重置。
- 日历展示最近 7 天：完成/未完成/今天。
- 不做补签、不做付费续签。

### 4.4 今日最佳

| 字段 | 说明 |
| --- | --- |
| date | 日期 YYYY-MM-DD |
| songId | 今日曲目 |
| bestScore | 当日最高分 |
| bestGrade | 当日最佳评级 |
| bestAccuracy | 当日最高准确率 |
| attempts | 当日完成次数 |
| completed | 是否完成过 |

- 只保留当日数据；跨天清空成绩，保留连续天数。
- 低分不覆盖高分；同分取更高评级。
- 今日最佳不写入曲目总最佳（F07 负责总最佳）。
- 每日挑战成绩可同时计入曲目总最佳（默认计入）。

### 4.5 分享卡片内容

卡片必须包含：

- 品牌：KeyTune / 键音。
- 曲名。
- 评级（S/A/B/C/D）与星级视觉。
- 分数（若有）。
- 准确率。
- 最大 Combo。
- 日期。
- 昵称（可选，默认“匿名演奏者”）。
- 装饰：琴键、音符、评级光效。

卡片不得包含：

- 设备型号、系统版本、IP、位置。
- 真实姓名、手机号、社交账号。
- 玩家未主动输入的隐私信息。
- 完整演奏记录或可识别个人习惯的详细数据。

### 4.6 分享预览

```text
┌──────────────────────────────────────────────┐
│ ← 分享成绩                              ✕    │
│                                              │
│   ┌────────────────────┐                     │
│   │                    │   比例 [竖版] [横版] │
│   │   卡片预览         │   昵称 [匿名演奏者] │
│   │                    │                     │
│   └────────────────────┘   [保存图片]        │
│                            [系统分享]        │
└──────────────────────────────────────────────┘
```

- 默认竖版 1080×1920，适合社交平台。
- 横版 1200×630 用于链接预览/桌面分享。
- 预览按屏幕缩放，保持比例，不裁切关键信息。
- 昵称输入最多 12 字，实时更新预览；不持久保存（或仅本机记住，需明确）。
- 保存图片：请求相册/下载权限（按平台），成功 Toast“已保存”。
- 系统分享：调用系统分享面板；不可用时降级为“保存图片”。
- 生成失败：提示“生成失败，请重试”，不阻塞返回。

### 4.7 分享模板变体

| 场景 | 模板 |
| --- | --- |
| 节奏挑战结算 | 评级为主，分数大 |
| 跟弹结算 | 准确率为主，无分数 |
| 每日挑战 | 增加“今日挑战”标识与连续天数 |
| 破纪录 | 增加“NEW RECORD”绶带 |
| 全曲 S / 全成就 | 特殊金色模板（P2 可选） |

- 首版至少支持前 3 种。
- 模板切换不改变数据，只改变布局与强调项。

### 4.8 隐私与权限

- 不要求登录、不读取通讯录、不读取相册。
- 保存图片时才请求写入相册/下载权限；拒绝后仍可预览。
- 系统分享由系统面板完成，应用不直接上传。
- 分享卡片生成在本地完成。
- 昵称仅用于本次卡片；若本机记住，需在设置中可清除。

## 6. 界面与交互要求

- 每日挑战入口在首页顶部，显示红点或“今日”标识。
- 今日曲目封面与曲库一致，不重复设计。
- 连续天数用火焰 + 数字，中断后不显示“断了”的责备文案。
- 分享按钮在无成绩时禁用，并说明“完成一次挑战后可分享”。
- 卡片预览不遮挡返回与比例切换。
- 昵称输入框不预填真实信息。
- 保存/分享按钮位于拇指区，间距 ≥24px。
- 减少动效时，卡片预览不做光效动画。

## 11. 风险与待确认

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 日期被修改 | 刷每日挑战 | 离线场景不防作弊；记录日期，异常时提示 |
| 今日曲目重复 | 连续几天同一首 | 日期种子 + 候选池排序；可加“最近 7 天不重复”规则（P2） |
| 卡片生成慢 | 低端机 >2s | 降低分辨率渲染后放大；预加载模板 |
| 分享权限 | 保存失败 | 降级为系统分享；提供重试 |
| 隐私顾虑 | 玩家不愿露昵称 | 默认匿名；昵称不持久或可清除 |
| 无链接可分享 | 只能发图 | 首版只做图片；链接分享 P2 |
