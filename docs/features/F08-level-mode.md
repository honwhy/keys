# F08 · 闯关模式

> **KeyTune · 键音 —— Play by Keys**
>
> KeyTune 是一款专为手机横屏设计的轻量音乐小游戏。玩家根据屏幕提示，在 15 键虚拟钢琴上按下对应琴键，跟随旋律完成演奏；系统用 PERFECT / GREAT / GOOD / MISS 判定每次按键，以 Combo、得分和评级给出即时反馈。你既可以跟着曲目挑战节奏，也可以自由弹奏、识别和弦，还能把整段演奏记录成可回放的作品。它不追求真实钢琴模拟，而是用「看得懂的音符 + 按得爽的琴键 + 停不下来的连击」，让任何人在 3 秒内上手、30 秒内完成第一段旋律。

## 1. Feature 概览

| 项目 | 内容 |
| --- | --- |
| 编号 | F08 |
| 阶段 | M4 有留存 |
| 优先级 | P1 |
| 依赖 | F03、F05、F07 |
| 被依赖 | F12（曲目池） |
| 一句话目标 | 把曲目与练习拆成章节关卡，用星级和解锁给玩家一条清晰的成长路线 |
| 对应需求 | FR-80～FR-83、9.6、7.5 |

### 1.1 本 Feature 包含

- 4 个章节、13 个关卡的内容编排。
- 闯关地图：章节切换、关卡节点、路径、进度。
- 关卡详情：目标、用键、最佳星级、开始。
- 星级结算与解锁规则。
- 章节完成奖励与下一章解锁。
- 闯关进度本地保存。

### 1.2 本 Feature 不包含

- 新的判定/计分规则（复用 F04）。
- 新的结算页（复用 F07）。
- 曲目谱面制作（复用 F03，新增练习关卡谱面归本 Feature）。
- 成就（F11）。

## 2. 用户故事

1. 作为新手，我希望从“只按 C”开始，一关一关学会更多键。
2. 作为玩家，我希望看到自己拿到了几颗星，哪一关还没满星。
3. 作为玩家，我希望通关后解锁下一关，有继续玩的理由。
4. 作为玩家，我希望自由选择已解锁的关卡重刷星级。
5. 作为玩家，我希望知道这一关要用哪些键、大概多难。

## 3. 业务流程

### 3.1 进入闯关

```text
首页 → 闯关
  ↓
进入第一章地图（默认定位到当前进度）
  ↓
左右滑动切换章节（仅已解锁章节）
  ↓
点击关卡节点 → 关卡详情
  ↓
开始 → 按关卡模式进入 F05 或 F06
  ↓
完成 → F07 结算 + 星级
  ↓
≥1 星 → 解锁下一关
```

### 3.2 关卡解锁

```text
关卡 N 完成
  ↓
计算星级（1～3）
  ↓
更新该关最高星级
  ↓
若 ≥1 星且 N+1 存在 → 解锁 N+1
  ↓
若本章全部关卡 ≥1 星 → 章节完成
  ↓
发放章节徽章 + 解锁下一章
```

### 3.3 重刷关卡

```text
选择已通关关卡
  ↓
开始
  ↓
完成
  ↓
星级取历史最高，不因低分下降
  ↓
若刷新更高星级 → 播放“新星级”提示
```

### 3.4 章节切换

```text
地图底部章节标签
  ├── 已解锁 → 切换地图
  ├── 未解锁 → 显示解锁条件，不可进入
  └── 当前章节 → 高亮
```

## 4. 功能设计

### 4.1 章节与关卡编排

| 章节 | 名称 | 主题 | 关卡数 | 解锁条件 |
| --- | --- | --- | --- | --- |
| 第一章 | 认识音符 | 三个白键起步 | 4 | 默认解锁 |
| 第二章 | 完整八度 | 七个白键 | 3 | 第一章全部 ≥1 星 |
| 第三章 | 黑键来了 | 五个黑键 | 3 | 第二章全部 ≥1 星 |
| 第四章 | 和弦色彩 | 双音与三和弦 | 3 | 第三章全部 ≥1 星 |

关卡清单：

| 关卡 | 名称 | 模式 | 用键 | 目标 | 对应内容 |
| --- | --- | --- | --- | --- | --- |
| 1-1 | 找到 C | 跟弹 | C4 | 按对 8 次 C | 原创练习 |
| 1-2 | C 与 D | 跟弹 | C4 D4 | 12 音 | 原创练习 |
| 1-3 | C-D-E | 跟弹 | C4 D4 E4 | 12 音 | S01 |
| 1-4 | 小星星 | 跟弹 | C4～A4 | 完整曲目 | S02 |
| 2-1 | 两只老虎 | 跟弹 | C4～G4 | 完整曲目 | S03 |
| 2-2 | 欢乐颂 | 节奏挑战 | C4～C5 | 完整曲目 | S04 |
| 2-3 | 生日快乐 | 节奏挑战 | C4～C5 | 完整曲目 | S05 |
| 3-1 | 黑键初见 | 跟弹 | C#4 D#4 | 10 音 | 原创练习 |
| 3-2 | 黑键五兄弟 | 跟弹 | 5 个黑键 | 15 音 | 原创练习 |
| 3-3 | 黑键小曲 | 节奏挑战 | C4～A#4 | 24 音 | 原创练习 |
| 4-1 | C 大三和弦 | 跟弹 | C4 E4 G4 | 8 次和弦 | 原创练习 |
| 4-2 | F 与 G 和弦 | 跟弹 | F4 A4 C5 / G4 B4 D5 | 8 次和弦 | 原创练习 |
| 4-3 | 和弦进行 | 节奏挑战 | C/F/G 和弦 | 12 次和弦 | S09 简化 |

- 练习关卡不进入曲库，只在闯关地图出现。
- 曲目关卡复用曲库谱面，不再复制一份。
- 关卡可标注“推荐音色”，但不强制。
- 练习关卡音符数控制在 8～24，单关 15～40 秒。

### 4.2 地图布局

以 1920×1080 为例：

```text
┌──────────────────────────────────────────────────────────┐
│ ← 闯关        第一章 · 认识音符        ★ 7 / 12          │
│                                                          │
│   ●━━━━●━━━━●━━━━●                                      │
│  1-1  1-2  1-3  1-4                                      │
│   ★★   ★★   ★☆☆  ★★★                                     │
│                                                          │
│        （横向卷轴，当前关卡居中）                         │
│                                                          │
│  [第一章] [第二章] [第三章] [第四章]                     │
└──────────────────────────────────────────────────────────┘
```

- 地图为横向卷轴，当前进度节点居中；可左右拖动。
- 节点之间用曲线路径连接；已通关路径点亮，未解锁路径变暗。
- 章节背景随章节变化（4 套）。
- 顶部显示章节名、总星数 / 满星数、返回。
- 底部章节标签可点击切换；未解锁章节显示锁。
- 当前可玩关卡有呼吸光与“继续”标签。

### 4.3 关卡节点

| 状态 | 外观 | 交互 |
| --- | --- | --- |
| 已通关 3 星 | 金色节点 + 三颗亮星 | 可重玩 |
| 已通关 1～2 星 | 青色节点 + 亮星/暗星 | 可重玩 |
| 当前可玩 | 青色呼吸节点 + 播放图标 | 可进入 |
| 未解锁 | 灰色节点 + 锁 | 点击提示条件 |
| 章节 Boss | 更大节点 + 皇冠 | 同普通关卡，通关解锁下一章 |

- 节点尺寸 128×128；Boss 节点 192×192。
- 星级显示在节点下方，三颗星 48×48。
- 未解锁节点不显示星级。
- 节点点击有按下缩放；不可用节点播放锁定音效。

### 4.4 关卡详情

```text
┌──────────────────────────────────────────────┐
│ ← 第一章 · 1-3                              │
│                                              │
│  C-D-E 练习曲                                │
│  跟弹 · Lv1 · 12 个音 · 约 20 秒             │
│  用键：C D E                                 │
│  最佳：★★☆                                  │
│                                              │
│  目标：跟着提示按对全部音符                  │
│                                              │
│  [ 开始 ]                                    │
└──────────────────────────────────────────────┘
```

- 显示关卡目标、模式、用键、时长、最佳星级。
- 练习关卡提供“试听”按钮，播放 5 秒示范。
- 开始按钮进入对应模式；音色/速度使用全局设置。
- 未解锁关卡不进入详情，直接提示条件。

### 4.5 星级规则

| 星级 | 条件 |
| --- | --- |
| 1 星 | 完成关卡（到达结算） |
| 2 星 | 评级 B 及以上 |
| 3 星 | 评级 A 及以上 |

- 跟弹关卡同样按 F04 的综合分与评级计算；无节奏误差时按准确率计入。
- 星级取历史最高。
- 新获得更高星级时，结算页显示“新星级”横幅，地图节点播放一次升级动画。
- 星级不因低分下降。

### 4.6 章节完成与奖励

- 章节全部关卡 ≥1 星 → 章节完成。
- 章节完成奖励：
  - 章节徽章（展示在章节标签与成就页）。
  - 解锁下一章。
  - 一次性完成音效与横幅。
- 不发放虚拟货币、不涉及付费。
- 最后一章完成：显示“全部章节完成”，并引导去挑战更高评级/自由演奏。
- 章节奖励只发放一次；重刷不重复发放。

### 4.7 进度保存

| 数据 | 说明 |
| --- | --- |
| levelStars | 每关最高星级 0～3 |
| levelCleared | 是否完成 |
| chapterUnlocked | 章节是否解锁 |
| chapterRewardClaimed | 章节奖励是否已发放 |
| lastLevelId | 最近游玩关卡 |
| totalStars | 总星数（派生） |

- 刷新、杀进程后不丢失。
- 存档损坏时，至少保留第一章可玩；提示进度可能重置。
- 清除成绩时同时清除闯关进度，需二次确认。

### 4.8 与曲库/每日挑战的关系

- 闯关进度不影响曲库曲目的可玩性（曲库默认全开，见需求文档待确认项）。
- 每日挑战的曲目池为“已解锁曲库曲目”，不包含练习关卡。
- 闯关中的曲目关卡与曲库共享最佳成绩，但闯关星级单独保存。

## 6. 界面与交互要求

- 地图横向滚动流畅，当前节点自动居中，不突然跳动。
- 已解锁与未解锁节点对比明显，不依赖颜色单一维度（锁图标 + 明度）。
- 星级亮/暗差异清晰，暗星仍可辨认。
- 底部章节标签不遮挡节点路径。
- 关卡详情开始按钮位于右下拇指区。
- 章节完成横幅不遮挡“下一章”按钮。
- 减少动效时，取消节点呼吸、路径流动、升级动画，保留状态变化。

## 11. 风险与待确认

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 关卡太少 | 玩得快 | 13 关 + 重刷星级；后续扩展 |
| 练习关枯燥 | 只有重复音 | 每关加一句旋律目标；控制 15～40 秒 |
| 星级门槛争议 | A 才 3 星偏难 | 观察分布；可调为 B+ |
| 曲库与闯关解锁冲突 | 玩家困惑 | 曲库全开，闯关独立进度（默认） |
| 地图性能 | 4 套大背景 | 懒加载 + 通用背景兜底 |
| 章节奖励太轻 | 缺乏动力 | 徽章 + 下一章 + 完成动画；不做付费 |
