# F04 · 判定、Combo 与计分核心

> **KeyTune · 键音 —— Play by Keys**
>
> KeyTune 是一款专为手机横屏设计的轻量音乐小游戏。玩家根据屏幕提示，在 15 键虚拟钢琴上按下对应琴键，跟随旋律完成演奏；系统用 PERFECT / GREAT / GOOD / MISS 判定每次按键，以 Combo、得分和评级给出即时反馈。你既可以跟着曲目挑战节奏，也可以自由弹奏、识别和弦，还能把整段演奏记录成可回放的作品。它不追求真实钢琴模拟，而是用「看得懂的音符 + 按得爽的琴键 + 停不下来的连击」，让任何人在 3 秒内上手、30 秒内完成第一段旋律。

## 2. 用户故事

1. 作为玩家，我按得准的时候希望看到 PERFECT，而不是所有按键都一样。
2. 作为玩家，我希望连续命中时 Combo 数字越来越大，分数涨得更快。
3. 作为玩家，我漏掉一个音时，希望 Combo 归零但歌曲继续，不会中断。
4. 作为玩家，我同时按 C、E、G 时，希望被当作一个和弦判定，而不是三次单音。
5. 作为玩家，我希望结算页的每个数字都能解释，不是随便给的。

## 3. 业务流程

### 3.1 单音判定

```text
谱面音符 N（音高 P，目标时间 T）
  ↓
玩家在 t 时刻按下音高 P
  ↓
计算偏差 Δ = t - T - 校准值
  ↓
|Δ| ≤ PERFECT 窗口 → PERFECT
|Δ| ≤ GREAT 窗口   → GREAT
|Δ| ≤ GOOD 窗口    → GOOD
|Δ| > GOOD 窗口    → 不匹配（继续等待或判 MISS）
  ↓
写入判定结果 → 更新 Combo → 更新分数 → 触发反馈
```

### 3.2 超时未按（MISS）

```text
音符到达目标时间 T
  ↓
超过 GOOD 窗口仍无有效按键
  ↓
标记 MISS
  ↓
Combo 归零
  ↓
播放 MISS 反馈
  ↓
音符从可判定队列移除
```

### 3.3 和弦判定

```text
目标音符组 {C4, E4, G4}，目标时间 T
  ↓
玩家在 T ± 120ms 内按齐三个音
  ↓
取三个音中最大的 |Δ| 作为该和弦的偏差
  ↓
按该偏差给出 PERFECT / GREAT / GOOD
  ↓
若窗口结束仍缺音 → MISS（整组）
  ↓
多按的音不参与该和弦，按“空击”处理
```

### 3.4 一局结束

```text
最后一个音符判定完成 + 2 秒余量
  ↓
停止接收新判定
  ↓
汇总：总数、四类数量、最大 Combo、分数、准确率、综合分
  ↓
交给 F07 展示与保存
```

## 4. 功能设计

### 4.1 判定窗口

标准严格度基准：

| 判定 | 时间差 | 基础分 | 准确率权重 |
| --- | --- | --- | --- |
| PERFECT | 0～±80ms | 100 | 1.00 |
| GREAT | ±81～±160ms | 70 | 0.80 |
| GOOD | ±161～±300ms | 40 | 0.50 |
| MISS | >±300ms 或未按 | 0 | 0 |

修正：

| 修正项 | 规则 |
| --- | --- |
| 严格度 | 宽松 ×1.3；标准 ×1.0；严格 ×0.75 |
| BPM | BPM ≥140 ×0.9；BPM ≤80 ×1.15 |
| 音画校准 | Δ = 实际按下时间 - 目标时间 - 校准值 |
| 取整 | 窗口四舍五入到 5ms，最大 500ms |
| 边界 | 恰好等于窗口上限，归入该档；例如 80ms 为 PERFECT |

示例（标准、BPM 100）：

| 偏差 | 判定 |
| --- | --- |
| 0ms / +79ms / -80ms | PERFECT |
| +81ms / -160ms | GREAT |
| +161ms / +300ms | GOOD |
| +301ms / 未按 | MISS |

### 4.2 按键匹配

- 一次按下只能匹配一个尚未判定的目标音符。
- 优先匹配“同音高、时间最近、尚未判定”的音符。
- 若最近音符已超出 GOOD 窗口，但更早的音符仍在窗口内，匹配更早的。
- 同一音符只判定一次；重复按下同音不重复得分。
- 空击：
  - 标准/宽松：不扣分、不断 Combo，播放轻微“哑音”反馈。
  - 严格（P1）：空击断 Combo，不扣分。
- 提前过多（早于 PERFECT 窗口但仍在 GOOD 外）的按键：视为空击，不消耗目标音符。
- 长音（P1）：按下判定起音，松开判定尾音；提前松开按 GOOD 或 MISS 处理。

### 4.3 Combo

- 每次 PERFECT / GREAT / GOOD 命中，Combo +1。
- MISS 或严格模式空击，Combo 归零。
- 跟弹模式：按错不归零（新手保护），但记录错误；只有连续按对才累加。
- Combo 只影响分数倍率与反馈，不影响判定。
- 最大 Combo 单独记录，用于结算与成就。

### 4.4 分数

```text
单音得分 = 基础分 × 当前 Combo 倍率
最终得分 = Σ 单音得分，四舍五入取整
```

Combo 倍率：

| 命中后的 Combo | 倍率 |
| --- | --- |
| 1～9 | ×1.0 |
| 10～19 | ×1.2 |
| 20～49 | ×1.5 |
| 50+ | ×2.0 |

示例：

| 事件 | 基础分 | 命中后 Combo | 倍率 | 得分 |
| --- | --- | --- | --- | --- |
| PERFECT | 100 | 1 | 1.0 | 100 |
| PERFECT | 100 | 9 | 1.0 | 100 |
| PERFECT | 100 | 10 | 1.2 | 120 |
| GREAT | 70 | 20 | 1.5 | 105 |
| GOOD | 40 | 50 | 2.0 | 80 |
| MISS | 0 | 0 | — | 0 |

- 分数只增不减。
- 跟弹模式不应用倍率放大，单音得分固定为基础分；结算展示准确率与最大 Combo。
- 曲目结束不额外奖励；连击奖励已体现在倍率中。

### 4.5 准确率与综合分

```text
准确率 = Σ 权重 / 总音符数
Perfect 率 = PERFECT 数 / 总音符数
Combo 率 = min(最大 Combo / 总音符数, 1)
节奏误差分 = max(0, 1 - 平均绝对偏差 / 300ms)
综合分 = 0.55×准确率 + 0.20×Perfect 率 + 0.15×Combo 率 + 0.10×节奏误差分
```

- 平均绝对偏差只统计命中音符，不含 MISS；MISS 已在准确率中体现。
- 跟弹模式无节奏误差时，节奏误差分按准确率计入。
- 所有比例保留 4 位小数参与计算，展示时保留 1 位百分比。
- 综合分用于 F07 的评级；F04 只输出原始值。

### 4.6 评级规则

| 评级 | 综合分 | 附加条件 |
| --- | --- | --- |
| S | ≥95% | 准确率 ≥98% 且 MISS ≤1 |
| A | ≥90% | 准确率 ≥90% |
| B | ≥80% | — |
| C | ≥60% | — |
| D | <60% | — |

- 不满足附加条件时降一级（S→A，A→B）。
- 评级取整按综合分四舍五入到 0.1% 后比较。
- 跟弹模式同样适用，但准确率按首按结果计算。

### 4.7 判定反馈

| 判定 | 文字 | 颜色 | 特效 | 音效 |
| --- | --- | --- | --- | --- |
| PERFECT | PERFECT | 青色 | 命中点爆裂 + 外环 | 清脆高音 |
| GREAT | GREAT | 金色 | 较小爆裂 | 中高音 |
| GOOD | GOOD | 白色 | 轻微闪光 | 中音 |
| MISS | MISS | 珊瑚红 | 判定线短暂变红 | 低频闷响 |

- 判定文字出现在判定线上方，向上飘 60px 后淡出，停留 500ms。
- 同一时刻多个判定：只显示优先级最高的一个（PERFECT > GREAT > GOOD > MISS），避免刷屏。
- Combo 里程碑：

| Combo | 反馈 |
| --- | --- |
| 10 | 火焰图标 ×1 + 轻震动 |
| 20 | 火焰 ×2 + 轻震动 |
| 50 | 火焰 ×3 + 中度震动 + 粒子 + 特殊音效 |
| 100 | 火焰 ×3 + 金色边框 + 粒子（每 50 连击重复） |

- 震动需受设置开关控制；无震动设备不报错。
- 减少动效开启时，取消粒子与屏幕震动，保留文字与颜色。

### 4.8 判定数据结构

每次判定至少输出：

| 字段 | 说明 |
| --- | --- |
| noteId | 目标音符标识 |
| pitches | 目标音高数组 |
| targetTime | 目标时间 |
| actualTime | 实际按下时间 |
| delta | 偏差（ms） |
| judgment | PERFECT / GREAT / GOOD / MISS |
| comboAfter | 判定后的 Combo |
| multiplier | 本次倍率 |
| scoreDelta | 本次得分 |
| isChord | 是否和弦 |
| isExtra | 是否空击 |

### 4.9 暂停与边界

- 暂停期间不产生判定、不推进目标时间。
- 继续时重新倒计时 3 秒，倒计时期间按键不计判定。
- 曲目结束后 2 秒内的按键不计分。
- 一局内切换严格度不生效，下一局生效。
- 校准值在每局开始时读取一次，局中修改不生效。

## 6. 界面与交互要求

- 判定文字不遮挡下一个音符与琴键。
- 判定颜色之外必须有文字与形状差异，色弱可辨。
- Combo 数字变化有轻微缩放，不遮挡轨道。
- 分数变化使用滚动数字，单次增量不超过 3 位，避免跳变。
- 命中特效在判定线附近，不覆盖整个屏幕。
- 连续快速命中时，特效合并而不是无限堆叠。
- 减少动效时，只保留判定文字与颜色。

| 指标 | 要求 |

| 判定延迟 | 按键到判定结果 ≤1 帧 |
| 并发判定 | 同一帧 3 个和弦、10 个按键不丢判定 |

| 空击处理 | 每秒 20 次空击不卡顿、不误判 |
| 设备差异 | 目标机型判定一致性误差 ≤20ms |

## 11. 风险与待确认

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 设备时钟不稳 | 长曲判定漂移 | 以音频时钟为准；每局校准 |
| 判定窗口主观 | 玩家觉得太严/太松 | 三档严格度；上线后看 MISS 分布 |
| 和弦误判 | 多按/少按 | 120ms 按齐；缺音整组 MISS；多按不吞 |
| 特效遮挡 | Combo/判定字挡住音符 | 固定区域；限制同时特效数量 |
| 音效过密 | 快速连打嘈杂 | 同判 50ms 节流；优先级混音 |
| 评级公式争议 | S 太难/太易 | 首版按文档；观察分布后调阈值 |
