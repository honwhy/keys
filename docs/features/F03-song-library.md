# F03 · 曲谱模型与曲库

> **KeyTune · 键音 —— Play by Keys**
>
> KeyTune 是一款专为手机横屏设计的轻量音乐小游戏。玩家根据屏幕提示，在 15 键虚拟钢琴上按下对应琴键，跟随旋律完成演奏；系统用 PERFECT / GREAT / GOOD / MISS 判定每次按键，以 Combo、得分和评级给出即时反馈。你既可以跟着曲目挑战节奏，也可以自由弹奏、识别和弦，还能把整段演奏记录成可回放的作品。它不追求真实钢琴模拟，而是用「看得懂的音符 + 按得爽的琴键 + 停不下来的连击」，让任何人在 3 秒内上手、30 秒内完成第一段旋律。

---

## 1. Feature 概览

| 项目 | 内容 |
| --- | --- |
| 编号 | F03 |
| 阶段 | M2 有游戏感 |
| 优先级 | P0 |
| 依赖 | F00 |
| 被依赖 | F05、F06、F08、F12 |
| 一句话目标 | 建立与玩法分离的曲谱内容模型，让 6 首首发曲目可浏览、可详情、可进入游戏 |
| 对应需求 | FR-30～FR-35、10.1、10.4 |

### 1.1 本 Feature 包含

- 曲谱内容模型与校验规则。
- 6 首首发曲目的谱面内容、难度、BPM、用键范围。
- 曲库页：分类、曲目卡片、最佳成绩、锁定状态。
- 曲目详情页：封面、信息、模式选择、最佳成绩、试听。
- 曲目数据与玩法逻辑分离；新增曲目只增加内容，不改玩法。
- 为跟弹/节奏挑战提供统一的谱面读取能力。

### 1.2 本 Feature 不包含

- 判定与计分（F04）。
- 跟弹/节奏挑战的具体玩法（F05/F06）。
- 闯关章节编排（F08）。
- 每日挑战选曲（F12）。

## 2. 用户故事

1. 作为玩家，我希望打开曲库就看到哪些歌简单、哪些歌难，以及我以前拿过什么成绩。
2. 作为第一次玩的玩家，我希望第一首曲子叫“C-D-E 练习曲”，一看就知道只用了三个键。
3. 作为玩家，我希望点开曲目能看到封面、BPM、时长，并选择跟弹或节奏挑战。
4. 作为玩家，我希望能试听一小段，确认是不是我想玩的歌。
5. 作为内容维护者，我希望新增一首歌只需要补一份谱面和一个封面，不需要改代码逻辑。

## 3. 业务流程

### 3.1 浏览曲库

```text
首页 → 曲库
  ↓
默认展示“全部”分类，按难度升序
  ↓
分类切换：全部 / 入门 / 初级 / 中级 / 和弦
  ↓
点击曲目卡片 → 曲目详情
  ↓
返回 → 保留分类与滚动位置
```

### 3.2 曲目详情与进入

```text
曲目详情
  ├── 试听（10～15 秒）
  ├── 查看最佳成绩
  ├── 选择“跟弹” → 模式准备 → F05
  └── 选择“节奏挑战” → 模式准备 → F06
```

### 3.3 谱面校验

```text
新增/修改曲谱
  ↓
字段完整性校验
  ├── 缺少必填 → 拒绝并指出字段
  ├── 音名不在 C4～E5 → 拒绝
  ├── time 非升序 → 自动排序或拒绝
  ├── duration ≤0 → 拒绝
  └── 同时音 >3 → 拒绝（首版）
  ↓
通过 → 进入曲库
```

## 4. 功能设计

### 4.1 曲谱内容模型

| 字段 | 类型 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- | --- |
| id | 字符串 | 是 | 小写字母/数字/连字符，唯一 | 如 `twinkle` |
| title | 字符串 | 是 | 1～20 字 | 中文名 |
| titleEn | 字符串 | 否 | 1～40 字符 | 英文名 |
| category | 枚举 | 是 | 入门/初级/中级/和弦 | 曲库分类 |
| difficulty | 整数 | 是 | 1～10 | 展示难度 |
| bpm | 整数 | 是 | 40～220 | 速度 |
| timeSignature | 字符串 | 否 | 默认 4/4 | 拍号 |
| duration | 整数 | 是 | 10000～300000ms | 曲目时长 |
| notes | 数组 | 是 | ≥1 | 音符列表 |
| notes[].notes | 字符串数组 | 是 | 1～3 个，C4～E5 | 同时发声 |
| notes[].time | 整数 | 是 | 0～300000ms，升序 | 相对开始 |
| notes[].duration | 整数 | 是 | 50～10000ms | 持续 |
| notes[].velocity | 数字 | 否 | 0.1～1.0 | 力度 |
| focusKeys | 字符串数组 | 否 | 子集 of 15 键 | 聚焦模式用键 |
| cover | 字符串 | 是 | 对应素材编号 | 封面 |
| previewStart | 整数 | 否 | 0～duration | 试听起点 |
| unlock | 对象 | 否 | 条件描述 | 曲库锁定 |
| tags | 字符串数组 | 否 | ≤5 个 | 如“儿歌”“黑键” |

示例：

```json
{
  "id": "twinkle",
  "title": "小星星",
  "titleEn": "Twinkle Twinkle Little Star",
  "category": "入门",
  "difficulty": 2,
  "bpm": 100,
  "timeSignature": "4/4",
  "duration": 32000,
  "focusKeys": ["C4", "D4", "E4", "F4", "G4", "A4"],
  "notes": [
    { "notes": ["C4"], "time": 0, "duration": 400 },
    { "notes": ["C4"], "time": 500, "duration": 400 },
    { "notes": ["G4"], "time": 1000, "duration": 400 }
  ],
  "cover": "M-IMG-04",
  "tags": ["儿歌", "入门"]
}
```

### 4.3 曲库页

布局：

```text
┌──────────────────────────────────────────────────────┐
│ ← 曲库                        最佳：A  已完 4/6      │
│ [全部] [入门] [初级] [中级] [和弦]                   │
│                                                      │
│ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐         │
│ │ 封面    │ │ 封面    │ │ 封面    │ │ 封面    │         │
│ │ 小星星  │ │ 两只老虎│ │ 欢乐颂  │ │ 生日快乐│         │
│ │ ★☆☆☆   │ │ ★☆☆☆   │ │ ★★☆☆   │ │ ★★☆☆   │         │
│ │ 最佳 A  │ │ 未游玩  │ │ 最佳 B  │ │ 最佳 A  │         │
│ └────────┘ └────────┘ └────────┘ └────────┘         │
└──────────────────────────────────────────────────────┘
```

- 横向滚动，每屏 4 张卡（窄屏 3 张）。
- 卡片包含封面、曲名、难度星、最佳评级、锁定图标。
- 未游玩显示“未游玩”，不显示空星误导。
- 锁定曲目：封面降亮 60%，右上角锁图标，点击提示解锁条件。
- 排序：难度升序，同难度按首发顺序。
- 分类切换不重新加载封面，避免闪烁。

### 4.4 曲目详情页

```text
┌──────────────────────────────────────────────────────┐
│ ←                                                    │
│ ┌──────────────┐  小星星                              │
│ │              │  Twinkle Twinkle Little Star         │
│ │    封面      │  入门 · Lv2 · 100 BPM · 32 秒        │
│ │              │  用键：C D E F G A                    │
│ └──────────────┘  最佳：A / 2,380 / Combo 24          │
│                                                      │
│ [ ▶ 试听 10 秒 ]                                     │
│                                                      │
│ [ 🎵 跟弹 ]        [ 🎮 节奏挑战 ]                    │
└──────────────────────────────────────────────────────┘
```

- 试听按钮播放 10～15 秒片段，再次点击停止。
- 跟弹/节奏挑战为两个主按钮，位于拇指易达区域。
- 最佳成绩按模式分别展示；无成绩显示“—”。
- 返回保留曲库位置。
- 若曲目未解锁，两个模式按钮禁用并展示条件。

### 4.5 试听规则

- 试听从 `previewStart` 开始，最长 15 秒，结尾 500ms 淡出。
- 试听时显示进度环，可随时停止。
- 试听不进入游戏、不记录成绩。
- 同时只允许一个试听；切换曲目自动停止上一首。
- 离开页面自动停止。

### 4.6 谱面读取与聚焦键

- 玩法读取统一字段：`notes`、`bpm`、`duration`、`focusKeys`。
- 若未提供 `focusKeys`，默认取谱面实际使用过的键。
- 聚焦模式只弱化未用键，不禁用。
- 曲目第一音前留 1 小节预备拍；最后一音后留 2 秒。
- 节奏挑战的下落时间由 BPM 与下落速度档位决定，不改变谱面时间。

### 4.7 内容校验与容错

| 情况 | 处理 |
| --- | --- |
| 曲谱字段缺失 | 该曲目不进入曲库，记录错误日志 |
| 音名非法 | 拒绝该音符；整曲校验失败 |
| notes 为空 | 不进入曲库 |
| time 重复 | 允许（和弦或快速重复） |
| time 逆序 | 自动升序排序并提示 |
| 同时音 >3 | 首版拒绝 |
| 曲目时长与最后音符不符 | 以最后音符 +2s 为准，展示时长同步 |
| 封面缺失 | 使用通用封面，不阻塞 |

### 4.8 最佳成绩展示

- 每曲每模式分别保存：最佳分数、最佳评级、最高 Combo、准确率、游玩次数。
- 曲库卡片显示“最佳评级”，详情页显示分数与 Combo。
- 无成绩不显示 0 分，显示“—”。
- 成绩由 F07 写入；本 Feature 只读取展示。

## 6. 界面与交互要求

- 封面统一 1:1，圆角 16px；不拉伸变形。
- 曲名最多 2 行；英文名可选，最多 1 行。
- 难度星使用形状 + 颜色双编码，色弱可辨。
- 锁定状态不显示“最佳成绩”，避免诱惑性误导。
- 试听按钮与模式按钮间距 ≥24px，防止误触。
- 曲库滚动惯性自然，滚动时封面不重新解码闪烁。
- 分类标签选中态明显；支持左右滑动切换分类（P1）。
- 减少动效开启时，卡片进入不做位移动画。

## 11. 风险与待确认

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 曲目版权 | 儿歌旋律可能涉及编曲版权 | 只使用公有领域旋律；编曲原创或已授权 |
| 谱面与试听不一致 | 玩家落差 | 试听由同一谱面生成，或严格对齐 |
| 曲目过少 | 玩得快 | 首发 6 首，V1.1 扩到 10 首 |
| 封面风格不统一 | 拼贴感 | 统一插画师/统一色板/统一构图 |
| 难度标注主观 | 玩家预期不符 | 用 7 维度评估；上线后按完成率调整 |
