# F05 · 跟弹模式（跟我弹）

> **KeyTune · 键音 —— Play by Keys**
>
> KeyTune 是一款专为手机横屏设计的轻量音乐小游戏。玩家根据屏幕提示，在 15 键虚拟钢琴上按下对应琴键，跟随旋律完成演奏；系统用 PERFECT / GREAT / GOOD / MISS 判定每次按键，以 Combo、得分和评级给出即时反馈。你既可以跟着曲目挑战节奏，也可以自由弹奏、识别和弦，还能把整段演奏记录成可回放的作品。它不追求真实钢琴模拟，而是用「看得懂的音符 + 按得爽的琴键 + 停不下来的连击」，让任何人在 3 秒内上手、30 秒内完成第一段旋律。

## 1. Feature 概览

| 项目 | 内容 |
| --- | --- |
| 编号 | F05 |
| 阶段 | M2 有游戏感 |
| 优先级 | P0 |
| 依赖 | F01、F03、F04 |
| 被依赖 | F07、F08 |
| 一句话目标 | 系统示范一句、玩家跟一句，在没有失败压力的前提下完成整首曲目 |
| 对应需求 | FR-40～FR-46、7.3、9.5 |

### 1.1 本 Feature 包含

- 曲目按乐句拆分。
- 每句“示范 → 轮到你 → 跟弹 → 反馈”的循环。
- 目标键高亮、示范播放、等待输入、错误提示、自动提示。
- 首按准确率与最大 Combo 统计。
- 聚焦模式：仅高亮曲目用键。
- 再听一次、跳过本句、暂停、退出。
- 完成后交给 F07 结算。

### 1.2 本 Feature 不包含

- 节奏挑战的下落音符（F06）。
- 严格节拍模式（P1，作为本 Feature 的扩展开关预留）。
- 结算页 UI（F07）。
- 闯关编排（F08）。

## 2. 用户故事

1. 作为完全不懂音乐的玩家，我希望先听一句，再照着亮起的键按，不需要识谱。
2. 作为玩家，我按错时希望被温和提醒，而不是被扣分或中断。
3. 作为玩家，我希望知道现在弹到整首曲子的哪里。
4. 作为玩家，我忘了下一句怎么弹，希望能再听一遍。
5. 作为玩家，我希望第一首曲子只用了三个键，很快就能弹完。

## 3. 业务流程

### 3.1 进入与准备

```text
曲目详情 → 跟弹
  ↓
准备页：音色（Piano/Bell/Synth）、是否聚焦、是否严格节拍（P1）
  ↓
点击“开始”
  ↓
3-2-1 倒计时（可听节拍）
  ↓
整曲第一句示范
```

### 3.2 单句循环

```text
第 N 句开始
  ↓
示范：逐个高亮目标键 + 播放该句旋律
  ↓
示范结束 → 提示“轮到你” + 目标键呼吸
  ↓
等待玩家输入
  ├── 按对 → 播放该音 + 前进到下一个音
  ├── 按错 → 温和提示 + 键帽抖动，不前进，允许重试
  ├── 停顿 5 秒 → 再次高亮目标键 + 播放提示音
  └── 点击“再听一次” → 重播本句示范，当前位置不变
  ↓
本句全部按对 → “很好！” + 句完成音效
  ↓
自动进入下一句示范
  ↓
最后一句完成 → 结算
```

### 3.3 错误与重试

```text
玩家按下非目标键
  ↓
该键仍发声（不静音，保持乐器感）
  ↓
目标键抖动 + 珊瑚色闪烁 + 轻柔提示音
  ↓
显示文字提示“再试一次”
  ↓
不扣 Combo、不扣分、不前进
  ↓
玩家继续按目标键
```

- 连续按错 3 次：自动重播当前音（不是整句），并放慢提示。
- 连续按错 5 次：显示“要不要再听一遍？”的轻提示，可点击重播本句。
- 错误不计入准确率的分母，只把该音标记为“非首按正确”。

### 3.4 暂停与退出

```text
点击暂停
  ↓
停止示范/停止等待计时/释放所有音
  ↓
暂停页：继续 / 再听本句 / 重开 / 退出
  ↓
继续 → 3 秒倒计时 → 从当前音继续
```

- 切后台自动暂停。
- 退出二次确认；未完成的进度不保存成绩。

### 3.5 完成

```text
最后一句完成
  ↓
整曲完成反馈（简短）
  ↓
汇总：首按准确率、最大 Combo、完成音符数、用时
  ↓
交给 F07 结算
```

## 4. 功能设计

### 4.1 乐句拆分

优先使用曲谱中显式标注的乐句；未标注时自动拆分：

| 规则 | 说明 |
| --- | --- |
| 静默间隔 | 相邻音符间隔 ≥2 拍，拆分为新句 |
| 最大长度 | 每句最多 8 个音符 |
| 最大小节 | 每句最多 4 小节 |
| 最小长度 | 每句至少 2 个音符；不足并入前句 |
| 首句 | 从第一个音开始，不额外补休止 |
| 尾句 | 最后一句可不足 8 个音 |

- 拆分结果在一局内固定，不随暂停改变。
- 每句开始时，目标键按顺序高亮；当前音高亮更强。
- 句与句之间留 1 拍呼吸，不自动跳过。

### 4.2 示范规则

- 示范速度 = 曲目 BPM；可在准备页选择 0.75× / 1.0×（P1）。
- 示范时逐个音高亮目标键，键帽发光 120ms，同时发声。
- 示范不显示判定，不产生 Combo。
- 示范结束到“轮到你”之间留 300ms，避免抢拍。
- 玩家在示范期间按键：不判错，但会被忽略；示范结束后才接收输入。
- 示范可随时点击“再听一次”重播，重播不改变当前进度。

### 4.3 等待与提示

- 目标键持续呼吸发光，强度 40%～100%，周期 1.2 秒。
- 目标音名显示在键盘上方，字号 48px，例如“按 C”。
- 停顿 5 秒：再次播放目标音，并让目标键闪 3 次。
- 停顿 15 秒：显示“点击这里再听本句”的轻提示。
- 不自动跳过、不自动替玩家按键。

### 4.4 输入判定

- 只判断“音高是否正确”，不判断时间（默认模式）。
- 按对：立即播放该音，前进；记为首按正确。
- 按错：播放该音，目标键抖动，不前进；记为该音首按错误。
- 同时按多个键：若包含目标音，视为按对；其他音正常发声，不额外惩罚。
- 和弦目标：需要按齐所有目标音（120ms 内）；缺音则提示还差哪个音（P1）。
- 重复按同一个正确音：不重复前进，第二次视为空击，不惩罚。

### 4.5 准确率与统计

```text
首按准确率 = 首按正确的音符数 / 总音符数
最大 Combo = 连续首按正确的最大长度
完成音符数 = 已正确完成的音符数
用时 = 从第一个音到最后一个音的实际时间
```

- 每个音只记录第一次按键结果；后续重试不改变首按结果。
- 跟弹模式不应用 Combo 倍率，不计算分数（结算展示准确率与 Combo）。
- 跳过本句：该句所有音标记为“跳过”，不计入准确率分子，但计入分母；结算显示“已跳过 N 句”。
- 重开：清空本局统计。

### 4.6 聚焦模式

- 开启后，非曲目用键透明度降至 45%，仍可发声。
- 目标键保持 100%，并带呼吸光。
- 聚焦键集合来自曲谱 `focusKeys`；未提供时取实际用键。
- 可在准备页开关；局中不可切换。
- 聚焦模式不影响判定，只影响视觉。

### 4.7 严格节拍（P1 预留）

- 开启后，跟弹也按目标时间判定，使用 F04 的窗口。
- 错误按键断 Combo；漏拍记 MISS。
- 适合已经熟悉曲目的玩家。
- 首版不默认开启；入口放在准备页“更多选项”。

### 4.8 曲目进度

- 顶部显示乐句进度点：已完成 / 当前 / 未开始。
- 显示“第 2 / 6 句”，不显示百分比，避免压力。
- 进度点数量等于乐句数；超过 8 句时折叠为进度条。
- 暂停、重播不改变进度。

## 6. 界面与交互要求

布局（1920×1080）：

```text
┌──────────────────────────────────────────────────────┐
│ ← 暂停     小星星        第 2 / 6 句    ●●○ ○ ○ ○     │
│                                                      │
│              ┌────────────────────┐                  │
│              │   轮到你 · 按 C     │                  │
│              └────────────────────┘                  │
│                                                      │
│         （目标键上方的高亮与音名提示）                │
│                                                      │
│  [再听一次]                                          │
│                                                      │
│  ┌────────────────────────────────────────────────┐  │
│  │                15 键键盘                        │  │
│  └────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────┘
```

- “轮到你”横幅在键盘上方 120px，不遮挡目标键。
- 示范时横幅显示“听一听”，颜色由青转金。
- 目标音名与目标键垂直对齐。
- 再听按钮位于左下拇指区，不与琴键重叠。
- 暂停按钮位于左上，尺寸 ≥64×64。
- 错误提示不使用红色大面积闪烁；仅目标键珊瑚色描边 + 轻微抖动。
- 减少动效时，取消呼吸与抖动，保留颜色与文字。

## 11. 风险与待确认

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 示范太长 | 玩家等待烦躁 | 每句 ≤8 音；可跳过示范（P1） |
| 玩家乱按 | 连续错误 | 3 次重播当前音；5 次建议重听；不惩罚 |
| 跟弹太简单 | 有经验玩家无聊 | 提供严格节拍；引导去节奏挑战 |
| 乐句拆分生硬 | 音乐性差 | 优先人工标注乐句；自动拆分兜底 |
| 提示音干扰 | 与旋律混淆 | 提示音用不同音色/音高；音量低 |
| 长时间停顿 | 玩家离开 | 15 秒显示轻提示；不自动退出 |
