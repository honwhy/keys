# F09 · 自由演奏与和弦识别

> **KeyTune · 键音 —— Play by Keys**
>
> KeyTune 是一款专为手机横屏设计的轻量音乐小游戏。玩家根据屏幕提示，在 15 键虚拟钢琴上按下对应琴键，跟随旋律完成演奏；系统用 PERFECT / GREAT / GOOD / MISS 判定每次按键，以 Combo、得分和评级给出即时反馈。你既可以跟着曲目挑战节奏，也可以自由弹奏、识别和弦，还能把整段演奏记录成可回放的作品。它不追求真实钢琴模拟，而是用「看得懂的音符 + 按得爽的琴键 + 停不下来的连击」，让任何人在 3 秒内上手、30 秒内完成第一段旋律。

## 1. Feature 概览

| 项目 | 内容 |
| --- | --- |
| 编号 | F09 |
| 阶段 | M3 有作品感 |
| 优先级 | P0 |
| 依赖 | F01、F02 |
| 被依赖 | F10、F11 |
| 一句话目标 | 没有任务也能玩：随便按、即时听到和弦名字、顺手就能录下来 |
| 对应需求 | FR-90～FR-97、9.7 |

### 1.1 本 Feature 包含

- 全键盘自由演奏，无任务、无判定、无失败。
- 同时按 2～4 个音的和弦/音程识别。
- 和弦名称中英双语展示、转位标识。
- 音色快速切换、节拍器、录制入口（录制细节由 F10 实现）。
- 演奏氛围视觉（轻量可视化，不干扰操作）。
- 首次进入自由演奏的轻引导。

### 1.2 本 Feature 不包含

- 录制事件的保存、列表、回放（F10）。
- 判定、Combo、分数（F04，不在此模式启用）。
- 曲目提示与下落音符（F05/F06）。

## 3. 业务流程

### 3.1 进入自由演奏

```text
首页 / 我的演奏 → 自由演奏
  ↓
键盘立即可用（无倒计时、无开始按钮）
  ↓
顶部显示当前音色、节拍器、录制按钮
  ↓
玩家按键
  ├── 单音 → 发声 + 键帽反馈 + 音名
  ├── 2～4 音同时 → 发声 + 和弦/音程识别
  └── 连续旋律 → 显示最近音符轨迹（可选）
```

### 3.2 和弦识别

```text
玩家按下若干音
  ↓
检测是否在 80ms 内同时按下 2～4 个不同音高
  ├── 否 → 不识别，显示“—”
  └── 是
        ↓
   归一化音高（去掉八度）
        ↓
   匹配和弦模板 / 音程模板
   ├── 匹配 → 显示英文名 + 中文名 + 转位
   └── 不匹配 → 显示“—”
        ↓
   按键变化（松开/新增）→ 重新识别
```

### 3.3 录制入口

```text
点击“录制”
  ↓
3-2-1 倒数（可在设置关闭）
  ↓
按钮变红，开始记录
  ↓
演奏
  ↓
点击“停止”
  ↓
试听 / 保存 / 重录 / 丢弃（F10）
```

### 3.4 节拍器

```text
点击节拍器图标
  ↓
展开 BPM 调节（40～200）
  ↓
开始/停止
  ↓
重拍有不同音色，弱拍较轻
  ↓
不参与录制事件（除非用户要求，默认不录）
```

## 4. 功能设计

### 4.1 自由演奏界面

以 1920×1080 为例：

```text
┌──────────────────────────────────────────────────────────┐
│ ← 自由演奏        [Piano] [Bell] [Synth]   ♩ 100   ● 录制 │
│                                                          │
│              ┌──────────────────────────┐                │
│              │      C Major             │                │
│              │      C 大三和弦           │                │
│              └──────────────────────────┘                │
│                                                          │
│         （轻量音浪/光点，随按键变化）                     │
│                                                          │
│  ┌────────────────────────────────────────────────────┐  │
│  │                 15 键键盘                          │  │
│  └────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

- 顶部：返回、标题、音色快速切换、节拍器、录制。
- 中部：和弦展示面板，占屏幕中上区域，不遮挡键盘。
- 背景：暗色 + 轻量音浪，按键时局部亮起。
- 键盘占据底部约 45% 高度，与游戏内键盘一致。
- 不显示判定线、分数、Combo。

### 4.2 和弦/音程识别

识别范围：

| 输入音数 | 识别内容 | 示例 |
| --- | --- | --- |
| 1 | 单音音名 | C4 |
| 2 | 音程名称，或强力和弦 | C4+E4 → 大三度；C4+G4 → C5 强力和弦 |
| 3 | 三和弦 | C4+E4+G4 → C Major / C 大三和弦 |
| 4 | 三和弦 + 八度重复 | C4+E4+G4+C5 → C Major / C 大三和弦 |
| 4（其他） | 不识别 | 显示“—” |

三和弦性质：

| 性质 | 音程 | 英文 | 中文 |
| --- | --- | --- | --- |
| 大三 | 0,4,7 | Major | 大三和弦 |
| 小三 | 0,3,7 | Minor | 小三和弦 |
| 减三 | 0,3,6 | Diminished | 减三和弦 |
| 增三 | 0,4,8 | Augmented | 增三和弦 |
| 挂二 | 0,2,7 | Sus2 | 挂二和弦 |
| 挂四 | 0,5,7 | Sus4 | 挂四和弦 |

规则：

- 以最低音为候选根音；若最低音不是根音，按转位处理。
- 转位显示：`C Major / C 大三和弦（第一转位）`。
- 根音用国际音名，黑键用升号（C#），不使用降号（Db），首版统一升号。
- 同时按下超过 4 个音：不识别，显示“—”，不猜测。
- 琶音（间隔 >80ms）：不识别为和弦；单音正常发声。
- 松开任一音后重新识别剩余音；不足 2 音回到单音/“—”。
- 识别结果变化时，250ms 淡入淡出，不闪烁。

音程名称（2 音）：

| 半音数 | 音程 | 半音数 | 音程 |
| --- | --- | --- | --- |
| 1 | 小二度 | 7 | 纯五度 |
| 2 | 大二度 | 8 | 小六度 |
| 3 | 小三度 | 9 | 大六度 |
| 4 | 大三度 | 10 | 小七度 |
| 5 | 纯四度 | 11 | 大七度 |
| 6 | 减五度 | 12 | 纯八度 |

- 2 音为纯五度时，额外显示“Power Chord / 强力和弦”。
- 2 音不显示转位。

### 4.3 和弦展示面板

| 状态 | 展示 |
| --- | --- |
| 无按键 | “随便弹点什么” + 轻提示 |
| 单音 | 大号音名 C4 + 小字“单音” |
| 2 音 | 音程名 + 两个音名 |
| 3～4 音匹配 | 英文名（大号）+ 中文名 + 转位 + 音名列表 |
| 不匹配 | “—” + “这个组合还没有名字” |
| 超过 4 音 | “—” + “同时按 2～4 个音试试” |

- 英文名最大 48px，中文名 28px，音名列表 20px。
- 面板 900×260，居中；不用全屏遮挡。
- 识别成功时面板轻微发光；不匹配时不报错、不变红。
- 新增/松开音时，面板内容 150ms 交叉淡入。

### 4.4 音色快速切换

- 顶部三个音色按钮：Piano / Bell / Synth。
- 点击立即切换，当前按住的音不中断，新音用新音色。
- 选中态明显；切换时播放 0.6 秒试听（可关闭）。
- 与 F02 的设置双向同步：这里切换后，设置页默认音色同步更新。

### 4.5 节拍器

- BPM 40～200，默认 100，步进 1；长按 +/- 连续调整。
- 拍号默认 4/4；首版不提供其他拍号。
- 重拍（每小节第一拍）音色更高，弱拍更低。
- 节拍器音量独立于音乐/效果？首版归入“效果音量”，可在面板内单独调 0～100。
- 开关状态在离开页面后保持。
- 节拍器不录入演奏记录（默认），避免回放时重复。
- 视觉节拍点：4 个小圆点，当前拍高亮；减少动效时仅颜色变化。

### 4.6 录制入口

- 顶部右侧红色圆形按钮，直径 96px。
- 未录制：红点 + “录制”。
- 录制中：红点脉冲 + 计时“00:12” + “停止”。
- 点击录制：若有未保存内容，先提示；否则 3-2-1 后开始。
- 录制中切换音色：允许，记录事件中标记音色变化。
- 录制中打开节拍器：允许，节拍器声音不录入。
- 录制最长 5 分钟，剩余 30 秒时按钮变黄提示；到 5 分钟自动停止并进入保存流程。
- 录制能力的保存/回放细节由 F10 实现；本 Feature 只提供入口与状态。

### 4.7 氛围视觉

- 背景为深色渐变 + 缓慢移动的光点；按键时对应区域亮起。
- 可选“音浪”可视化：按键强度驱动一条横向波形，位于和弦面板下方。
- 波形不显示具体音高，仅作氛围；不遮挡键盘。
- 减少动效：关闭光点移动与波形动画，保留按键高亮。
- 低端设备：自动关闭光点，仅保留静态背景。

### 4.8 首次引导

- 首次进入自由演奏，和弦面板显示“同时按住 2～4 个音，看看它叫什么”。
- 3 秒后若仍无按键，键盘上方出现一次轻提示箭头指向 C/E/G。
- 不弹窗、不强制。
- 玩家成功识别一次和弦后，引导永久消失。

## 6. 界面与交互要求

- 自由演奏无“开始”按钮，进入即可弹。
- 和弦面板不遮挡琴键与顶部按钮。
- 顶部按钮在左右两侧，给中间留出演奏视野。
- 录制按钮醒目但不误触；与音色按钮间距 ≥40px。
- 和弦名称过长时缩小字号或换行，不截断关键性质。
- 转位标识用括号，不与和弦名混淆。
- 不匹配状态不使用红色、不播放失败音。
- 减少动效时，取消脉冲与波形，保留颜色变化。

## 11. 风险与待确认

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 和弦误报 | 玩家按错也被命名 | 80ms 严格同时；不匹配显示“—”；不猜测 |
| 4 音歧义 | 七和弦/转位混淆 | 首版只识别三和弦 + 八度重复 |
| 识别面板抢注意力 | 影响弹奏 | 面板固定在上方，不遮挡键盘 |
| 节拍器与录制混淆 | 回放出现额外节拍 | 默认不录节拍器；录制说明明确 |
| 录制入口误触 | 丢失演奏 | 录制前提示；停止后先试听再保存 |
| 氛围动画耗电 | 长时间演奏发热 | 低端设备关闭光点；减少动效可用 |
