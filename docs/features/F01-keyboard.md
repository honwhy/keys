# F01 · 15 键键盘与即时发声

> **KeyTune · 键音 —— Play by Keys**
>
> KeyTune 是一款专为手机横屏设计的轻量音乐小游戏。玩家根据屏幕提示，在 15 键虚拟钢琴上按下对应琴键，跟随旋律完成演奏；系统用 PERFECT / GREAT / GOOD / MISS 判定每次按键，以 Combo、得分和评级给出即时反馈。你既可以跟着曲目挑战节奏，也可以自由弹奏、识别和弦，还能把整段演奏记录成可回放的作品。它不追求真实钢琴模拟，而是用「看得懂的音符 + 按得爽的琴键 + 停不下来的连击」，让任何人在 3 秒内上手、30 秒内完成第一段旋律。

## 1. Feature 概览

| 项目 | 内容 |
| --- | --- |
| 编号 | F01 |
| 阶段 | M1 能玩 |
| 优先级 | P0 |
| 依赖 | F00 |
| 被依赖 | F02、F04、F05、F06、F09、F10 |
| 一句话目标 | 在横屏上稳定呈现 15 个琴键，按下即发出正确音高，支持多指与滑动 |
| 对应需求 | FR-10～FR-16、NFR-03、NFR-04、NFR-07 |

### 1.1 本 Feature 包含

- 10 白键 + 5 黑键的布局、绘制、按下态。
- 单键、多键、和弦、滑奏的触摸处理。
- 音高映射、按下发声、松开停声、自然衰减。
- 琴键高亮、音名浮字、触摸涟漪。
- 键盘的“可交互 / 只读预览 / 聚焦 / 禁用”四种状态。
- 桌面鼠标与键盘映射兜底。
- 为上层玩法提供“按下 / 松开 / 高亮 / 取消高亮”的交互能力。

### 1.2 本 Feature 不包含

- 音色选择、音量设置（F02）。
- 判定、计分、曲目提示（F04～F06）。
- 录制与回放（F10）。

## 2. 用户故事

1. 作为第一次上手的玩家，我按下任意琴键就能立刻听到声音，不用先选音色或点开始。
2. 作为玩家，我想同时按下 C、E、G，三个音要一起响，不能只响一个。
3. 作为玩家，我想手指从 C 滑到 G，连续听到每个音，而不是卡住。
4. 作为玩家，我不小心把手指滑出琴键时，声音应该停止，不能一直响。
5. 作为桌面用户，我可以用鼠标点，也可以用键盘弹。

## 3. 业务流程

### 3.1 单键按下

```text
手指/鼠标接触琴键
  ↓
命中检测（以触点为圆心，命中最近且最上层琴键）
  ↓
键帽进入按下态（缩放/下沉/发光）
  ↓
音名浮字出现（C / C#）
  ↓
触发发声（音高 = 该键）
  ↓
手指抬起 / 移出
  ↓
键帽回弹 + 声音释放（短衰减）
```

### 3.2 多指与和弦

```text
第 1 指按下 C → 发声
第 2 指按下 E → 发声（C 保持）
第 3 指按下 G → 发声（C、E 保持）
  ↓
三音同时存在 → 交由 F09 识别和弦（本 Feature 只保证发声）
  ↓
任一手指抬起 → 仅该音停止，其他音不受影响
```

### 3.3 滑奏

```text
手指按住并横向移动
  ↓
进入新琴键 → 新音发声，旧音停止
  ↓
离开琴键区域 → 停止当前音
  ↓
快速滑过多个键 → 每个键触发一次，不重复叠加
```

### 3.4 多指丢失与恢复

```text
系统取消触摸 / 来电 / 切后台
  ↓
所有按下的音立即释放（50ms 内淡出）
  ↓
清除所有键帽按下态
  ↓
回到前台不自动补发声音
```

## 4. 功能设计

### 4.1 键位布局

| 类型 | 数量 | 音名（左→右） | 视觉位置 |
| --- | --- | --- | --- |
| 白键 | 10 | C4 D4 E4 F4 G4 A4 B4 C5 D5 E5 | 等宽平铺 |
| 黑键 | 5 | C#4 D#4 F#4 G#4 A#4 | 位于 C-D、D-E、F-G、G-A、A-B 之间 |

- 黑键不占用白键宽度，悬浮在白键上方，高度约为白键的 62%。
- 黑键宽度约为白键的 60%，居中对齐两白键交界。
- E-F、B-C 之间没有黑键，保持空缺。
- 第二八度只有 C5、D5、E5 三个白键，右侧不延伸黑键。

### 4.2 尺寸与自适应

以 1920×1080 逻辑画布、键盘区宽 1840 为例：

| 元素 | 逻辑尺寸 | 说明 |
| --- | --- | --- |
| 键盘区 | 1840×420 | 左右各留 40px |
| 白键 | 184×420 | 含 2px 间隔，可见宽 180 |
| 黑键 | 112×260 | 顶部对齐，圆角 12 |
| 键帽圆角 | 白键 16 / 黑键 12 | 底部圆角略大 |
| 白键音名 | 28px | 距底部 32px |
| 黑键音名 | 20px | 距底部 20px，白色文字 |
| 按下下沉 | 6px | 配合亮度变化 |
| 发光范围 | 键宽 +40px | 不遮挡相邻键 |

自适应规则：

- 键盘宽度 = 屏幕安全区宽度 × 0.96；白键宽度 = 键盘宽度 / 10。
- 白键最小可见宽 56 CSS px；低于该值时提示“屏幕过窄，建议横屏”。
- 键盘高度 = min(屏高 × 0.42, 白键宽 × 2.6)；不低于是 260 CSS px。
- 刘海屏左右安全区内缩，琴键不被遮挡。
- 平板/桌面：键盘最大宽度 1840 CSS px，居中，不无限拉伸。

### 4.3 触摸命中规则

- 以触点的中心点判定；命中黑键优先于白键。
- 触点落在黑键的圆角外、但仍在包围盒内：按白键处理。
- 一个触点同一时刻只属于一个琴键。
- 多指按下同一键：只发一次声，所有手指抬起后才释放（引用计数）。
- 手指从键 A 滑到键 B：A 释放、B 按下；不产生额外音。
- 手指滑出键盘区：释放当前音。
- 触摸取消（系统打断）：释放该触点对应的音。

### 4.4 发声规则

| 项目 | 规则 |
| --- | --- |
| 音高 | 十二平均律，A4=440Hz |
| 起音 | 按下后立即起音，无预延迟 |
| 释放 | 松开后 80～150ms 衰减；Piano 可更长 |
| 同时发声 | 至少 5 个音；目标支持 10 个 |
| 重复按同键 | 先释放再起音，或快速重新触发，不叠成两路 |
| 静音 | 静音时不出声，但保留视觉反馈 |
| 音量 | 由 F02 的总音量/音乐音量控制；本 Feature 不单独设音量 |
| 爆音 | 起音与释放均需斜坡，禁止咔哒声 |

标准音高：

| 音名 | 频率（Hz） | 音名 | 频率（Hz） |
| --- | --- | --- | --- |
| C4 | 261.63 | C#4 | 277.18 |
| D4 | 293.66 | D#4 | 311.13 |
| E4 | 329.63 | F4 | 349.23 |
| F#4 | 369.99 | G4 | 392.00 |
| G#4 | 415.30 | A4 | 440.00 |
| A#4 | 466.16 | B4 | 493.88 |
| C5 | 523.25 | D5 | 587.33 |
| E5 | 659.25 | — | — |

### 4.5 视觉反馈

- 按下：键帽下沉 6px、亮度 +10%、边缘发光；黑键发光更明显。
- 音名浮字：按下后 400ms 内向上浮 40px 并淡出；白键深色字、黑键浅色字。
- 涟漪：触点位置扩散圆环，300ms 消失；仅触摸触发，鼠标不显示。
- 多键同时按下：每个键独立反馈，不互相遮挡。
- 高亮（由玩法调用）：目标键呼吸发光，不改变按下态；与按下态可叠加。
- 聚焦模式：非曲目用键透明度降至 45%，仍可发声；目标键恢复 100%。

### 4.6 键盘状态

| 状态 | 使用场景 | 行为 |
| --- | --- | --- |
| 可交互 | 首页、自由演奏、游戏 | 可按键、发声、反馈 |
| 只读预览 | 结算页、曲目详情 | 不响应触摸，仅展示 |
| 聚焦 | 跟弹新手、闯关教学 | 非目标键弱化，目标键高亮 |
| 禁用 | 加载中、弹窗阻断 | 不响应，视觉降亮 |

### 4.7 桌面兜底

- 鼠标按下/抬起模拟单指；不支持鼠标多键。
- 键盘映射（P1）：`A S D F G H J K L ;` 对应 10 个白键，`W E T Y U` 对应 5 个黑键。
- 按键重复（长按）不重复触发；以 keydown/keyup 为准。
- 窗口失焦时释放所有音。

### 4.8 上层接口（行为约定）

供 F04～F10 使用的能力，不涉及实现方式：

- 订阅“某键按下”，携带音名、时间、力度。
- 订阅“某键松开”，携带音名、时间。
- 请求“高亮某键 / 取消高亮 / 清空高亮”。
- 请求“设置聚焦键集合 / 退出聚焦”。
- 请求“以指定音色、音量、时长播放某音”（用于示范与回放，不经过触摸）。
- 请求“释放全部音”，用于暂停、切后台、页面退出。

## 6. 界面与交互要求

- 键盘固定在屏幕底部，游戏模式中不因判定文字、Combo 动画而位移。
- 琴键之间的间隔清晰可见，白键不互相粘连。
- 黑键不遮挡白键音名；白键音名位于黑键下方可视区。
- 手指遮挡是常态：按下态与发光需从手指边缘可见，不能只在键帽中心。
- 琴键标签可在设置中关闭；关闭后仍保留按下浮字。
- 低亮度环境下，白键不刺眼；黑键与背景有足够明度差。
- 横屏左右手拇指自然覆盖区域（屏幕左右下角）必须包含最左与最右琴键。
- 减少动效开启时，取消涟漪与浮字位移动画，仅保留颜色变化。

## 11. 风险与待确认

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 小屏键宽不足 | 15 键在 5.5 英寸上拥挤 | 白键最小 56px；黑键最小 40px；提示横屏 |
| 多指断触 | 部分安卓机型限制同时触控 | 目标 5 指；真机矩阵测试；卡键 100ms 释放 |
| 黑键误触 | 黑键面积小 | 黑键命中区域比视觉大 8px；圆角外归白键 |
| 音频延迟 | 触感到发声超标 | 起音无预延迟；必要时提供校准（F02） |
| 滑奏叠音 | 快速滑动重复触发 | 每个触点仅保留一个活动音；进入新键先释放旧音 |
| 采样体积 | 15 个音过大 | 优先合成；采样按需加载、单音 ≤150KB |
