# F02 · 音色、音量与声音设置

> **KeyTune · 键音 —— Play by Keys**
>
> KeyTune 是一款专为手机横屏设计的轻量音乐小游戏。玩家根据屏幕提示，在 15 键虚拟钢琴上按下对应琴键，跟随旋律完成演奏；系统用 PERFECT / GREAT / GOOD / MISS 判定每次按键，以 Combo、得分和评级给出即时反馈。你既可以跟着曲目挑战节奏，也可以自由弹奏、识别和弦，还能把整段演奏记录成可回放的作品。它不追求真实钢琴模拟，而是用「看得懂的音符 + 按得爽的琴键 + 停不下来的连击」，让任何人在 3 秒内上手、30 秒内完成第一段旋律。

### 1.1 本 Feature 包含

- Piano / Bell / Synth 三种音色的听感与切换。
- 主音量、音乐音量、效果音量三路调节。
- 混响强度（关/低/中）。
- 判定严格度与音画校准的设置入口（规则由 F04 执行）。
- 设置面板、试听、实时生效、持久保存。
- 静音快捷开关。

### 1.2 本 Feature 不包含

- 具体判定窗口算法（F04）。
- 曲目伴奏与游戏内音乐（F06）。
- 分享、成就音效（后续 Feature）。

## 2. 用户故事

1. 作为玩家，我希望默认的 Piano 听起来自然，不需要调任何东西就能开始。
2. 作为喜欢清脆声音的玩家，我希望切到 Bell 后，小星星听起来更轻快。
3. 作为在安静环境里的玩家，我希望把总音量调低，但不影响按键反馈。
4. 作为戴耳机的玩家，我希望音乐和音效可以分开调，不被伴奏盖住按键声。
5. 作为对延迟敏感的玩家，我希望校准后按键判定更贴合我听到的声音。

## 3. 业务流程

### 3.1 音色切换

```text
设置 / 游戏准备页 / 自由演奏
  ↓
点击音色卡片（Piano / Bell / Synth）
  ↓
卡片选中态切换
  ↓
播放 1 秒试听（当前音色，C4→E4→G4）
  ↓
立即应用到后续所有发声
  ↓
保存设置
```

规则：

- 正在按住的音不中断；新按下的音使用新音色。
- 连续快速切换时，只保留最后一次选择，试听不叠加。
- 游戏进行中切换音色：仅自由演奏与暂停页允许；挑战进行中禁用，避免干扰。

### 3.2 音量调节

```text
拖动滑杆 / 点击 + -
  ↓
数值实时变化（0～100，步进 5）
  ↓
声音实时变化（无爆音）
  ↓
松手后保存
```

- 三路音量相互独立：总音量 × 音乐音量 × 效果音量。
- 拖动过程中不逐帧写存档，松手后 300ms 保存。
- 调节到 0 时显示静音图标，但不自动关闭其他两路。

### 3.3 校准流程

```text
设置 → 音画校准
  ↓
播放 4 下节拍（视觉闪烁 + 声音）
  ↓
玩家按提示点击“听到声音时点我”
  ↓
系统计算平均偏移
  ↓
展示建议值（-200ms～+200ms）
  ↓
玩家确认 / 手动微调
```

- 校准只影响判定时间，不改变声音播放时间。
- 校准值为正表示“声音比画面晚”，判定时相应补偿。
- 允许手动拖动，步进 10ms。

### 3.4 恢复默认

```text
设置 → 声音 → 恢复默认
  ↓
确认弹窗
  ↓
主 80 / 音乐 70 / 效果 80 / Piano / 混响低 / 校准 0
```

## 4. 功能设计

### 4.1 三种音色

| 音色 | 听感目标 | 起音 | 衰减 | 适用场景 | 默认 |
| --- | --- | --- | --- | --- | --- |
| Piano | 柔和、温暖、自然衰减 | 8～15ms | 中长 | 跟弹、儿歌、自由演奏 | 是 |
| Bell | 明亮、泛音丰富、尾巴较长 | 3～8ms | 长 | 小星星、生日快乐 | 否 |
| Synth | 电子、短促、有游戏感 | 2～5ms | 短 | 节奏挑战、电子风曲目 | 否 |

要求：

- 三种音色在 C4～E5 全音域音高准确。
- 同一键位在三种音色下音量感知接近，切换不忽大忽小。
- 和弦状态下不浑浊；三音同时按下仍能分辨各音。
- 不使用真实钢琴采样也可以，但必须“像一种乐器”，不能是单纯正弦蜂鸣。

### 4.2 音量模型

| 控制 | 范围 | 默认 | 影响 |
| --- | --- | --- | --- |
| 主音量 | 0～100 | 80 | 所有声音 |
| 音乐音量 | 0～100 | 70 | 曲目伴奏、示范旋律、节拍器 |
| 效果音量 | 0～100 | 80 | 按键声、判定音效、UI 音效 |

- 最终响度 = 主 × 音乐（或效果），采用感知曲线，不是简单线性相乘。
- 任一路为 0 时，对应声音完全静音。
- 调节过程中峰值不超过 -1dBTP，不出现爆音。
- 静音快捷开关：一键将主音量设为 0，再次点击恢复上次值。

### 4.3 混响

| 档位 | 听感 | 适用 |
| --- | --- | --- |
| 关 | 干声，最直接 | 低延迟优先、耳机 |
| 低 | 轻微空间感 | 默认 |
| 中 | 明显舞台感 | 外放、氛围 |

- 混响只作用于乐器与音乐，不作用于 UI 点击音效。
- 改变混响不改变判定时间。
- 低端设备可自动降为“关”，但需在设置中可见当前实际档位。

### 4.4 判定严格度

| 档位 | 窗口系数 | 适用 |
| --- | --- | --- |
| 宽松 | ×1.3 | 儿童、首次游玩 |
| 标准 | ×1.0 | 默认 |
| 严格 | ×0.75 | 有音游经验者 |

- 本 Feature 只提供入口与保存；F04 读取并执行。
- 修改后下一局生效，当前局不中途改变。
- 设置页展示三档的实际毫秒窗口，便于理解。

### 4.5 音画校准

- 范围 -200ms～+200ms，步进 10ms，默认 0。
- 提供“自动测试”和“手动调节”两种方式。
- 自动测试最多 8 次点击，去掉最大/最小各 1 次后取平均。
- 结果偏差 >150ms 时提示“建议检查蓝牙耳机或设备音频设置”。
- 校准值对所有模式生效，包括回放。

### 4.6 设置面板交互

```text
┌─────────────────────────────────────────────┐
│ 声音设置                              ✕     │
│                                             │
│ 音色                                        │
│ ┌────────┐ ┌────────┐ ┌────────┐           │
│ │ Piano  │ │ Bell   │ │ Synth  │           │
│ │  ●     │ │        │ │        │           │
│ └────────┘ └────────┘ └────────┘           │
│                                             │
│ 主音量      ─────────●────────  80          │
│ 音乐音量    ───────────●──────  70          │
│ 效果音量    ─────────●────────  80          │
│                                             │
│ 混响        [关] [低●] [中]                 │
│ 判定严格度  [宽松] [标准●] [严格]           │
│ 音画校准    -200ms ───●─── +200ms   0ms     │
│                                             │
│ [试听]                         [恢复默认]   │
└─────────────────────────────────────────────┘
```

- 滑杆支持拖动与点击轨道跳转；拖动时显示数值气泡。
- 音色卡片点击即试听，不需要额外“试听”按钮；底部“试听”用于完整三音试听。
- 所有控件支持键盘操作（桌面端）。
- 修改后立即生效，无需“保存”按钮。

### 4.7 声音不可用兜底

| 场景 | 表现 |
| --- | --- |
| 浏览器禁止自动播放 | 首次交互前不发声；交互后恢复；不弹错误 |
| 音频设备被占用 | 提示“未检测到可用音频设备”，仍可游玩但无声 |
| 切换耳机/蓝牙 | 声音自动切到新设备；若延迟明显，提示校准 |
| 系统静音 | 游戏内仍显示音量；提示“设备可能处于静音” |

## 6. 界面与交互要求

- 设置面板最大宽度 1200px，横屏居中，左右留白。
- 音色卡片展示图标 + 名称 + 一句听感描述；选中态有边框与勾选。
- 滑杆轨道高 ≥8px，拖拽点 ≥44×44px。
- 数值实时显示，单位“%”；校准显示“ms”。
- 试听按钮不遮挡滑杆；试听时按钮显示波形动画。
- 减少动效开启时，试听波形改为静态。
- 所有设置修改有轻微视觉确认（选中态/数值变化），不需要额外 Toast。

## 11. 风险与待确认

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 三种音色响度不一致 | 切换时忽大忽小 | 统一响度校准；切换试听对比 |
| 混响增加延迟 | 影响手感 | 混响不进入判定链路；低端设备降级 |
| 蓝牙耳机延迟 | 校准复杂 | 提供校准；提示检查设备 |
| 自动播放限制 | 首次无声音 | 首次交互后恢复；不报错 |
| 设置项过多 | 新手困惑 | 默认值合理；高级项折叠到“更多” |
