# F11 · 成就系统

> **KeyTune · 键音 —— Play by Keys**
>
> KeyTune 是一款专为手机横屏设计的轻量音乐小游戏。玩家根据屏幕提示，在 15 键虚拟钢琴上按下对应琴键，跟随旋律完成演奏；系统用 PERFECT / GREAT / GOOD / MISS 判定每次按键，以 Combo、得分和评级给出即时反馈。你既可以跟着曲目挑战节奏，也可以自由弹奏、识别和弦，还能把整段演奏记录成可回放的作品。它不追求真实钢琴模拟，而是用「看得懂的音符 + 按得爽的琴键 + 停不下来的连击」，让任何人在 3 秒内上手、30 秒内完成第一段旋律。

## 1. Feature 概览

| 项目 | 内容 |
| --- | --- |
| 编号 | F11 |
| 阶段 | M4 有留存 |
| 优先级 | P1 |
| 依赖 | F00、F04、F09、F10 |
| 被依赖 | F12 |
| 一句话目标 | 用 10 个明确的里程碑，让玩家在“第一次按键、第一次通关、第一次 50 Combo”时被看见 |
| 对应需求 | FR-110～FR-113、9.9 |

### 1.1 本 Feature 包含

- 10 个成就的定义、触发条件、进度计算。
- 成就解锁判定、去重、持久化。
- 解锁 Toast、成就页、分类、进度、说明。
- 与键盘、结算、自由演奏、录制、曲库的触发对接。
- 成就与分享卡片的展示字段（F12 使用）。

### 1.2 本 Feature 不包含

- 新的玩法内容。
- 虚拟奖励、货币、皮肤。
- 全球排名、服务器校验。

## 2. 用户故事

1. 作为新手，我第一次按键就解锁“第一个音”，希望有被欢迎的感觉。
2. 作为玩家，我希望看到还差多少才能解锁某个成就，而不是只有一个灰图标。
3. 作为玩家，我达成 50 Combo 时，希望立刻知道，而不是事后才看到。
4. 作为收藏型玩家，我希望有一个页面展示我拿到的所有成就。
5. 作为玩家，我希望成就不会被重复弹出、也不会丢。

## 3. 业务流程

### 3.1 解锁触发

```text
玩家行为（按键/完成曲目/达成 Combo/保存记录/识别和弦）
  ↓
上报事件给成就系统
  ↓
遍历未解锁成就
  ↓
检查条件与进度
  ├── 未达成 → 更新进度（若可累计）
  └── 达成 → 标记解锁 + 记录时间
        ↓
     加入 Toast 队列
        ↓
     当前界面无阻断时展示
```

### 3.2 Toast 展示

```text
成就达成
  ↓
若正在游戏：延迟到结算页展示，不打断演奏
  ↓
若在非游戏页：右上角滑入 Toast，停留 2.5 秒
  ↓
点击 Toast → 打开成就页并定位该成就
  ↓
多个成就：排队，间隔 1 秒，最多连续 3 个
```

### 3.3 成就页浏览

```text
首页 → 成就
  ↓
默认“全部”，已解锁在前
  ↓
分类：全部 / 入门 / 进阶 / 大师
  ↓
点击成就 → 详情弹层（条件、进度、解锁时间）
  ↓
返回首页
```

## 4. 功能设计

### 4.1 成就清单

| 编号 | 名称 | 条件 | 类型 | 分类 | 触发点 |
| --- | --- | --- | --- | --- | --- |
| A01 | 第一个音 | 第一次按下任意琴键并发声 | 一次性 | 入门 | 键盘 down |
| A02 | 初学者 | 完成第一首曲目（任意模式） | 一次性 | 入门 | 结算 |
| A03 | 连击达人 | 单局达到 50 Combo | 一次性 | 进阶 | 判定 |
| A04 | 八度大师 | 累计按下全部 10 个白键 | 累计 | 进阶 | 键盘 down |
| A05 | 黑键入门 | 第一次按下任意黑键 | 一次性 | 入门 | 键盘 down |
| A06 | 和弦大师 | 第一次成功识别三和弦 | 一次性 | 进阶 | 和弦识别 |
| A07 | 完美演奏 | 一首曲目准确率 100%（全部 PERFECT） | 一次性 | 大师 | 结算 |
| A08 | 我的作品 | 保存第一条演奏记录 | 一次性 | 入门 | 记录保存 |
| A09 | 演奏家 | 完成 10 首不同曲目 | 累计 | 大师 | 结算 |
| A10 | 钢琴大师 | 全部曲目达到 S 评级 | 终局 | 大师 | 结算 |

### 4.2 条件细则

| 成就 | 判定细节 |
| --- | --- |
| A01 | 任意键、任意页面；首次发声即解锁 |
| A02 | 跟弹或节奏挑战到达结算即算完成；中途退出不算 |
| A03 | 同一局内 Combo 达到 50；跟弹模式的连续首按正确也计入 |
| A04 | 累计按键，不要求同一局；白键 10 个各按过至少一次 |
| A05 | 任意黑键；与 A04 可同时触发 |
| A06 | 三音和弦（3 个不同音高）识别成功；转位也算 |
| A07 | 结算准确率 100%，且 MISS=0、GOOD=0、GREAT=0（全部 PERFECT） |
| A08 | 任意来源保存成功；从结算保存也算 |
| A09 | 10 首不同曲目各完成至少一次；练习关卡不计入曲目数 |
| A10 | 曲库内全部曲目均达到 S；不含练习关卡；新增曲目后需重新满足 |

### 4.3 进度计算

| 成就 | 进度展示 |
| --- | --- |
| A01 | 0/1 → 1/1 |
| A02 | 0/1 → 1/1 |
| A03 | 本局最高 Combo / 50；历史最高 / 50 |
| A04 | 已按白键数 / 10 |
| A05 | 0/1 → 1/1 |
| A06 | 0/1 → 1/1 |
| A07 | 0/1 → 1/1 |
| A08 | 0/1 → 1/1 |
| A09 | 已完成不同曲目数 / 10 |
| A10 | 已获 S 曲目数 / 曲库总数 |

- 进度为派生的，不单独维护复杂状态；以档案中的成绩、记录、按键集合计算。
- 成就解锁后进度固定为满，不再变化。
- 未解锁成就显示条件文案 + 进度条；A10 显示“3 / 6”这类分数。

```text
┌──────────────────────────────────────────────────────────┐
│ ← 成就                  已解锁 6 / 10        ★ 6        │
│ [全部] [入门] [进阶] [大师]                              │

│ │ 已解锁 │ │ 已解锁 │ │ 已解锁 │ │ 6/10   │            │
│ └────────┘ └────────┘ └────────┘ └────────┘            │
│                                                          │
│ ┌────────┐ ┌────────┐ ┌────────┐ ...                    │
│ │  🔒    │ │  🔒    │ │  🔒    │                        │
```

- 4 列网格，窄屏 3 列；卡片 320×320。
- 已解锁：彩色图标 + 名称 + 解锁日期（可选）。
- 未解锁：灰度图标 + 锁 + 条件 + 进度条。
- 顶部显示总进度与总星数。
- 分类标签与曲库一致。
- 卡片点击打开详情弹层，不直接跳转。

### 4.5 解锁 Toast

```text
┌──────────────────────────────────────┐
│  🏆  成就解锁                         │
│      连击达人                         │
│      单局达到 50 Combo                │
│                            [查看]     │
└──────────────────────────────────────┘
```

- 尺寸 900×220，右上角滑入，停留 2.5 秒。
- 金色描边 + 轻微光效；不遮挡琴键、判定线、结算主按钮。
- 游戏中不弹出，排队到结算；若玩家中途退出，回到首页后再展示。
- 点击“查看”打开成就页并高亮该成就。
- 多个成就排队，间隔 1 秒；同一成就永不重复。
- 减少动效：直接淡入淡出，无滑入。

### 4.6 持久化

| 数据 | 说明 |
| --- | --- |
| unlocked | 成就 id → 解锁时间 |
| whiteKeysPlayed | 已按过的白键集合 |
| blackKeyPlayed | 是否按过黑键 |
| completedSongIds | 已完成的不同曲目集合 |
| bestComboEver | 历史最高 Combo |
| sGradeSongIds | 已获 S 的曲目集合 |
| toastSeen | 已展示过的解锁（避免重复） |

- 每次相关事件后更新；写入失败时保留内存，下一次事件重试。
- 刷新、杀进程后不丢失已解锁状态。
- 清除成绩与成就时，全部清空，需二次确认。

### 4.7 与其它 Feature 的对接

| 来源 | 上报事件 | 可解锁 |
| --- | --- | --- |
| F01 键盘 | keyDown(note) | A01、A04、A05 |
| F04 判定 | comboChanged(n) | A03 |
| F05/F06 结算 | songCompleted(result) | A02、A07、A09、A10 |
| F09 和弦 | chordRecognized(chord) | A06 |
| F10 保存 | recordSaved(record) | A08 |

- 上报幂等：同一事件重复上报不重复解锁。
- 结算类成就在 F07 结算页统一检查，避免游戏中弹窗。
- 成就检查不影响游戏帧率；单次检查 ≤5ms。

### 4.8 成就详情弹层

- 大图标、名称、分类、条件、当前进度、解锁时间。
- 未解锁：条件文案 + 进度条 + “去完成”按钮（跳转相关页面）。
- 已解锁：解锁时间 + “已达成”印章 + 分享按钮（P2）。
- “去完成”跳转：
  - A02/A07/A09/A10 → 曲库。
  - A03 → 节奏挑战推荐曲。
  - A06 → 自由演奏。
  - A08 → 自由演奏并高亮录制按钮。

## 6. 界面与交互要求

- 成就卡片 4 列（宽屏）/3 列（窄屏），间距 24px。
- 已解锁/未解锁对比明显；锁图标 + 灰度 + 进度三重表达。
- 成就名称不超过 8 字，说明不超过 30 字。
- Toast 不覆盖顶部返回、暂停、结算主按钮。
- 成就页可滚动，滚动时分类标签吸顶。
- 减少动效：取消滑入、光效、印章旋转。
- 所有成就图标有文字名称，不依赖图标猜含义。

## 11. 风险与待确认

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 成就太难 | A10 全 S 遥不可及 | 作为终局目标；其余 9 个可在前 30 分钟解锁 |
| 成就太容易 | 缺少成就感 | A03/A07/A10 设门槛；解锁有仪式感 |
| 游戏中弹窗打断 | 影响演奏 | 一律延迟到结算 |
| 成就重复触发 | 多次 Toast | 永久去重 + toastSeen |
| 进度计算复杂 | A04/A09/A10 | 用档案派生；页面打开时重算 |
| 新增曲目影响 A10 | 已解锁变未解锁 | 成就一旦解锁不回收；进度按当前曲库重算 |
